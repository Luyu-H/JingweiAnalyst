# Index of knowledge fragments

One line per fragment. The `summary` column is the text a retrieval step can show to the model when it picks fragments; the full file is loaded only for the fragments it picks.

Generated by `python -m src.docs.knowledge_index` from the front matter of each fragment. Do not edit by hand; edit the fragment and regenerate.

Severity: **must** = ignoring it produces a wrong number; **should** = ignoring it produces a misleading comparison or interpretation; **info** = background for interpretation.

## Methods: how to compute or compare

| id | severity | variables | summary |
|---|---|---|---|
| [anomaly-baselines-and-climate-indices](methods/anomaly-baselines-and-climate-indices.md) | must | tos, thetao, so | An anomaly from a field's own climatology removes its bias (what an index, a trend or a comparison between two products needs), one from an observed climatology keeps it; an anomaly is defined only relative to its baseline period, so series on different baselines differ by an offset; DJF and JFM seasons must not be mixed; events and outliers are judged on anomalies, with persistence. |
| [common-comparison-mask](methods/common-comparison-mask.md) | must | tos, thetao, so, o2, no3, po4, dissic, talk, ph | A bias, RMSE or pattern correlation between two fields exists only where both have data, and several models' cell-by-cell scores can be ranked only on the cells all of them cover; for a cell-by-cell comparison of one field put the fields on one grid, build one mask over all of them and apply it to every field (a pattern that an analysis produced on each source's own domain, such as a variability mode, is correlated with the reference over the cells the two share), and keep WOA23's land-sea mask out of comparisons WOA23 is not part of (GLODAP, for instance). |
| [basin-and-region-definitions](methods/basin-and-region-definitions.md) | should | basin | OMIP's recommended 10-region tracer mask separates the Southern Ocean, marginal seas and the Arctic from the Atlantic/Pacific/Indian basins, while overturning uses Atlantic–Arctic / Indo-Pacific / global; basin statistics depend on which partition is used and must say so. |
| [derive-unavailable-diagnostics](methods/derive-unavailable-diagnostics.md) | should | sos, tob, sob, chlos, o2min, zo2min, msftmz, obvfsq, thkcello, zos, spco2, fgco2, intpp, epc100, hfds | A lookup from commonly requested CMIP6 ocean variables that are not stored locally (sos, tob, sob, chlos, o2min, zo2min, msftmz, obvfsq, thkcello, zos, spco2, fgco2, intpp, epc100, hfds) to their CMOR definition and to a derivation from local variables, or to "not derivable". |
| [eof-modes-and-pdo-index](methods/eof-modes-and-pdo-index.md) | should | tos, thetao | The PDO is the leading EOF of North Pacific SST anomalies with the global-mean anomaly removed; EOFs are area-weighted, their sign is a convention, explained variance depends on grid, domain and record length, and a mode's amplitude is read from its regression pattern on the standardised index, compared between sources with an area-weighted correlation. |
| [ocean-heat-and-salt-content](methods/ocean-heat-and-salt-content.md) | should | thetao, so, volcello, areacello | Model heat content is c_p × prognostic temperature × ρ dV with the model's own constant heat capacity (TEOS-10 value 3991.87 J kg-1 K-1) and, for Boussinesq models, a constant reference density; changes are scale-independent, absolute values are not; 1 W m-2 over a decade warms the global ocean by ~0.02 °C. |
| [omip-native-grid-vs-regridded](methods/omip-native-grid-vs-regridded.md) | should | thetao, so, o2, no3, areacello | CMIP6 protocol puts diagnostics on native grids for conservation; regridding changes the land-sea mask and breaks conservation even with "conservative" methods, so compute integrals and budgets natively and regrid only for maps and pattern comparisons. |
| [omip-weighted-means-and-integrals](methods/omip-weighted-means-and-integrals.md) | should | thetao, so, tos, areacello, volcello | OMIP global means are volume-weighted (Boussinesq) or mass-weighted (non-Boussinesq) over all ocean cells; surface means are area-weighted over the top level; integrals use every grid point in the region with no subsampling. |
| [overturning-from-mass-transport](methods/overturning-from-mass-transport.md) | should | msftmz, msftyz, vmo, vo, umo, uo | The overturning streamfunction is Ψ(y,z) = −∫∫ ρ v† dz dx in kg s-1, reported for Atlantic–Arctic, Indo-Pacific and global basins; msftmz is not in the local archive, so it must be built from vmo (MPI only) or vo, along native grid rows, with mass Sv = 1e9 kg s-1. |
| [serial-correlation-and-significance](methods/serial-correlation-and-significance.md) | should | – | Monthly ocean series and neighbouring ocean cells are strongly autocorrelated, so naive sample sizes overstate the information: trend intervals and correlation p-values need an effective sample size, a trend question needs an explicit straight-line fit quoted with its interval, shared trends inflate correlations, and fitted relations need spatially blocked validation. |
