The user's question:
Assess the Pacific Decadal Oscillation (PDO) simulated by three CMIP6 models against ERSSTv5 observations, over 1950-01 to 2014-12.

Data to use:
- CMIP6 historical `tos` from CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly, 1950-01 to 2014-12.
- ERSSTv5 monthly SST over the same window.
- The published PDO index (product `pdo` in the index registry).

The PDO is the leading EOF of monthly North Pacific SST anomalies over 20N-70N, 110E-100W, relative to a 1950-2014 monthly climatology.

Expected numerical results, for each of the four sources over 1950-2014, with any regridding done by bilinear interpolation onto the 1-degree grid:
- The percentage of variance explained by the leading mode, to 1 decimal place.
- The amplitude of the mode, in degrees Celsius per standard deviation, to 3 decimal places.
- The lag-1-year (12-month) autocorrelation of the monthly standardized index, to 3 decimal places.

- The observed PDO phase-transition years over 1950-2014, defined as the years in which the 9-year (108-month) centred running mean of the ERSSTv5 index changes sign (a crossing less than 3 years after the last counted transition is merged into it, keeping the earlier year), and which of them correspond to documented Pacific climate shifts.
- Which model reproduces the observed pattern best, and whether the models' amplitude and persistence are consistent with observations.

- Figure 1, a 2-by-2 panel of the regression pattern over the PDO domain, in the order ERSSTv5, CESM2, GFDL-ESM4, MPI-ESM1-2-LR, on one diverging colour scale centred on zero labelled in degrees Celsius per standard deviation, each panel annotated with its explained variance and, for the models, its pattern correlation with observations.

# ---------------- PDO assessment: ERSSTv5 vs three CMIP6 models, 1950-2014 ----------------
# Baseline: each field's own 1950-2014 monthly climatology. All fields are bilinearly regridded
# to the 1-degree grid first. compute_pdo_index receives the GLOBAL field and removes the global-mean
# anomaly itself, then takes the leading EOF over 20N-70N, 110E-100W.

t0, t1 = "1950-01", "2014-12"
base = ["1950-01", "2014-12"]
models = ["CESM2", "GFDL-ESM4", "MPI-ESM1-2-LR"]
names = ["ERSSTv5"] + models


def month_start(da):
    """Put the time axis on month-start timestamps so indices from different sources align."""
    tt = pd.to_datetime(da["time"].values).to_period("M").to_timestamp()
    return da.assign_coords(time=tt)


def in_pdo_domain(da):
    lon360 = da["lon"] % 360
    return (da["lat"] >= 20) & (da["lat"] <= 70) & (lon360 >= 110) & (lon360 <= 260)


raw = {}
raw["ERSSTv5"] = load_regular_data(dataset="ersst", variable="sst", time_range=[t0, t1])
for m in models:
    raw[m] = load_regular_data(dataset="cmip6_historical", variable="tos", model=m,
                               time_range=[t0, t1])

pdo_index = {}
eof_pattern = {}
expl_var = {}
reg_pattern = {}
sst_1deg_anom = {}
global_mean_anom = {}
amplitude = {}
ac12 = {}

for name in names:
    f = raw[name]
    # mask unmasked fill values (~1e20)
    f = f.where(np.abs(f) < 1e10)
    units = str(f.attrs.get("units", "")).lower()
    if units in ("k", "kelvin"):
        f = transform_unit(f, from_unit="K", to_unit="degC")
    # global field onto the common 1-degree grid (bilinear, as prescribed)
    f1 = regrid_horizontal(f, target="1deg", method="bilinear").compute()
    # anomaly relative to own 1950-2014 monthly climatology
    an = compute_anomaly_vs_own_climatology(f1, freq="month", base_period=base)
    sst_1deg_anom[name] = an
    # area-weighted global-mean SST anomaly on the 1-degree field (reported; the tool removes it internally)
    global_mean_anom[name] = compute_basic_stat(an, op="area_weighted_mean", dim=["lat", "lon"]).compute()

    # PDO: leading EOF on the global field (box cut and global-mean removal inside the tool)
    idx, eof, ev, reg = compute_pdo_index(an, standardize=True)
    idx = month_start(idx.compute())
    pdo_index[name] = idx
    eof_pattern[name] = eof.compute()
    expl_var[name] = float(ev)
    reg = reg.compute()
    reg_pattern[name] = reg.where(in_pdo_domain(reg))

    # amplitude: area-weighted RMS of the regression pattern (degC per standard deviation)
    msq = compute_basic_stat(reg_pattern[name] ** 2, op="area_weighted_mean", dim=["lat", "lon"])
    amplitude[name] = float(np.sqrt(float(msq.compute())))

    # lag-12-month autocorrelation of the standardised monthly index
    ac = analyze_correlation(idx, idx, dim="time", lag=12)
    ac12[name] = float(ac["correlation"])

# ---------------- ERSSTv5 index vs published PDO (as is, no detrending) ----------------
pub = load_regular_data(dataset="cpc_indices", product="pdo", time_range=[t0, t1]).compute()
pub = month_start(pub)
pub = pub.where(pub > -90)  # drop any missing-value flags
obs_idx, pub_a = xr.align(pdo_index["ERSSTv5"], pub, join="inner")
cc = analyze_correlation(obs_idx, pub_a, dim="time", detrend=False)
corr_pub = float(cc["correlation"])
p_pub_corrected = float(cc["pvalue"])
p_pub_raw = float(cc["pvalue_unadjusted"])
n_pub = int(cc["n_samples"])
n_eff_pub = float(cc["n_effective"])
pub_std = (pub_a - pub_a.mean("time")) / pub_a.std("time")

# ---------------- spatial pattern correlation with ERSSTv5 (area weighted, no shared mask) ----------------
pattern_corr = {}
pattern_ncells = {}
for m in models:
    sc = analyze_correlation(reg_pattern[m], reg_pattern["ERSSTv5"], dim=["lat", "lon"],
                             weighting="area")
    pattern_corr[m] = float(sc["correlation"])
    pattern_ncells[m] = int(sc["n_samples"])
best_model = max(pattern_corr, key=pattern_corr.get)

# ---------------- PDO phase transitions of the ERSSTv5 index ----------------
smooth = temporal_aggregate(pdo_index["ERSSTv5"], freq="rolling", window=108, center=True).compute()
up = detect_threshold_events(smooth, 0.0, direction="above", min_duration=1)
dn = detect_threshold_events(smooth, 0.0, direction="below", min_duration=1)
runs = []
for _, r in up.iterrows():
    runs.append((pd.Timestamp(r["start"]), pd.Timestamp(r["end"]), "positive"))
for _, r in dn.iterrows():
    runs.append((pd.Timestamp(r["start"]), pd.Timestamp(r["end"]), "negative"))
runs.sort(key=lambda x: x[0])
# first run starts at the edge of the valid record, so it is not a crossing
crossings = [(r[0], r[2]) for r in runs[1:]]

counted = []
for t, sign in crossings:
    if counted and (t - counted[-1][0]).days / 365.25 < 3.0:
        continue  # merged into the earlier transition
    counted.append((t, sign))
transition_times = [c[0] for c in counted]
transition_years = [t.year for t in transition_times]
transition_signs = [c[1] for c in counted]

documented = []
for y in transition_years:
    if abs(y - 1977) <= 1:
        documented.append("1976/77 shift")
    elif abs(y - 1998) <= 2:
        documented.append("late-1990s (1998/99) shift")
    else:
        documented.append("no documented match")
transition_table = pd.DataFrame({"year": transition_years, "new_phase": transition_signs,
                                 "documented_shift": documented})

# ---------------- model vs observation consistency ----------------
consistency = {}
for m in models:
    consistency[m] = {
        "amplitude": amplitude[m],
        "amplitude_ratio_to_obs": amplitude[m] / amplitude["ERSSTv5"],
        "ac12": ac12[m],
        "ac12_diff_from_obs": ac12[m] - ac12["ERSSTv5"],
        "amplitude_consistent(+-25%)": abs(amplitude[m] / amplitude["ERSSTv5"] - 1) <= 0.25,
        "persistence_consistent(+-0.1)": abs(ac12[m] - ac12["ERSSTv5"]) <= 0.1,
    }

summary = pd.DataFrame({
    "explained_variance_%": {n: round(expl_var[n], 1) for n in names},
    "amplitude_degC_per_sd": {n: round(amplitude[n], 3) for n in names},
    "lag12_autocorr": {n: round(ac12[n], 3) for n in names},
    "pattern_corr_vs_ERSSTv5": {n: (round(pattern_corr[n], 3) if n in pattern_corr else np.nan) for n in names},
    "n_cells": {n: (pattern_ncells[n] if n in pattern_ncells else np.nan) for n in names},
})
print(summary)
print("ERSSTv5 index vs published PDO: r = %.3f, corrected p = %.3g (raw p = %.3g), n = %d, n_eff = %.1f"
      % (corr_pub, p_pub_corrected, p_pub_raw, n_pub, n_eff_pub))
print(transition_table)
print("Best pattern:", best_model)

# --- visualization ---
fig, axes = plt.subplots(2, 2, figsize=(13, 8), constrained_layout=True)
vals = []
panels = {}
for n in names:
    p = reg_pattern[n].assign_coords(lon=reg_pattern[n]["lon"] % 360).sortby("lon").sortby("lat")
    p = p.sel(lat=slice(20, 70), lon=slice(110, 260))
    panels[n] = p
    vals.append(np.abs(p.values[np.isfinite(p.values)]))
vmax = float(np.nanpercentile(np.concatenate(vals), 98))

im = None
for ax, n in zip(axes.ravel(), names):
    p = panels[n]
    im = ax.pcolormesh(p["lon"], p["lat"], p.values, cmap="RdBu_r", vmin=-vmax, vmax=vmax,
                       shading="auto")
    txt = "EV = %.1f%%" % expl_var[n]
    if n in pattern_corr:
        txt += "\nr(pattern) = %.3f" % pattern_corr[n]
    ax.text(0.02, 0.04, txt, transform=ax.transAxes, fontsize=10,
            bbox=dict(facecolor="white", alpha=0.8, edgecolor="none"))
    ax.set_title(n)
    ax.set_xlim(110, 260)
    ax.set_ylim(20, 70)
    ax.set_xlabel("Longitude (°E)")
    ax.set_ylabel("Latitude (°N)")
cb = fig.colorbar(im, ax=axes, orientation="vertical", extend="both", shrink=0.85)
cb.set_label("°C per standard deviation")
fig.suptitle("PDO regression patterns, 1950-2014 (1° bilinear grid; colour scale clipped at 98th percentile)")

fig2, ax2 = plt.subplots(figsize=(14, 5), constrained_layout=True)
colors = {"ERSSTv5": "k", "CESM2": "tab:blue", "GFDL-ESM4": "tab:green", "MPI-ESM1-2-LR": "tab:orange"}

Over 1950–2014 on the 1° bilinear grid, all three CMIP6 models produce a leading North Pacific SST mode that resembles the ERSSTv5 PDO. **CESM2 reproduces the observed spatial pattern best (r = 0.925)**, followed by GFDL-ESM4 (0.891) and MPI-ESM1-2-LR (0.750). ## 2. What was actually done

- **Data.**
  - `load_regular_data` was called with only a time range of 1950-01 to 2014-12, so global fields were loaded. The PDO box was applied later, inside `compute_pdo_index` and in the masking of the regression patterns.
  - Sources were ERSSTv5 `sst` (native 89×180, about 2°), CMIP6 historical `tos` for the three models on their native grids (CESM2 nlat/nlon, GFDL-ESM4 lat/lon, MPI-ESM1-2-LR j/i), and the published `pdo` series from `cpc_indices`.

- **Anomalies.** `compute_anomaly_vs_own_climatology(freq="month", base_period=["1950-01","2014-12"])` was applied to each field, so the baseline is each field's own 1950–2014 monthly climatology. ## 5. Caveats

- The EOF sign convention, the sqrt(cos lat) weighting and the global-mean removal are performed inside `compute_pdo_index`; the script does not independently verify them.
- The results use bilinear regridding, as prescribed. The native-grid differences (CESM2 and MPI-ESM1-2-LR are native `gn`, GFDL-ESM4 is 1° `gr`, ERSSTv5 is about 2°) mean the regridding affects the sources differently. Coarse grids cannot reproduce narrow features in amplitude.
- Offsets against the published PDO reflect baseline and construction differences rather than reconstruction errors.
- Because the pattern correlations are over about 4400–4600 spatially autocorrelated cells, no significance is attached to them.
