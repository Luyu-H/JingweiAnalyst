The user's question:
Check whether a mixed layer depth (MLD) computed from each CMIP6 model's own temperature and salinity reproduces the mlotst field that the same model publishes. This is an internal consistency test: both quantities come from the same simulation, so any disagreement is a property of the diagnostic, not of the model's physics.

Data to use:
- CMIP6 historical `thetao`, `so` and `mlotst` from CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly, 1971-01 to 2000-12.
- Each model's own published cell areas (areacello).

Expected numerical results, comparing the 1971-2000 March and September climatologies of the operator MLD with those of the published mlotst, for each of the six model-and-month combinations. The operator MLD is the mixed layer depth computed offline from the model's own thetao and so with the density criterion that defines mlotst, the crossing depth interpolated between the bracketing levels. For each model and calendar month, both climatologies cover only the cells where both fields are defined in all 30 instances of that month (the 30 Marches, or the 30 Septembers):
- The mean difference, operator MLD minus mlotst, in metres to 1 decimal place.
- The root-mean-square difference, in metres to 1 decimal place.
- The spatial Pearson correlation between the two fields, to 3 decimal places.
- The percentage of the area where both fields are defined on which the absolute difference exceeds 20 m, to 1 decimal place, and the area where both fields are defined as a percentage of the model's total ocean area, to 1 decimal place.
- The ranking of the three models from most to least internally consistent, with the criterion used, the regions where the disagreement concentrates, and why the operator and mlotst are not expected to agree exactly.

Expected visualizations:
- Figure 1, a 3-by-2 panel of global maps of operator MLD minus mlotst, rows CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, columns March and September, all six panels drawn as maps on a common longitude-latitude frame (each panel a true geographic map, with curvilinear model fields put on a regular longitude-latitude grid for display only) with one shared diverging colour scale centred on zero.
- Figure 2, a 3-by-2 panel of scatter plots in the same layout, operator MLD on the x axis against mlotst on the y axis, one point per ocean cell, with logarithmic axes of identical range and ticks in every panel, a dashed y = x reference line, and each panel annotated with its bias, root-mean-square difference and correlation.

2. Load each model's vertical coordinate with `load_depth_levels` (level centres and layer boundaries) for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR.
   - Note [cmip6-mlotst-definition]: compute the MLD as a displaced surface parcel compared with the local parcel at each level's in-situ pressure (δB = −g(ρ_displaced − ρ_local)/ρ_local), taking the first level where δB > 0.0003 m s⁻² (Δρ_crit = 0.03 kg m⁻³), linearly interpolated between the bracketing levels, with `ref_depth` set to the model's shallowest level rather than 10 m; compute the MLD of each monthly profile and average the MLDs afterwards (never average `thetao`/`so` first); exclude columns that never reach the threshold, report the area excluded, and state the three definitional differences (reference level, σ0-difference versus displaced-parcel comparison, averaging order) so the residual against `mlotst` is not read as model error; expect the offline MLD to be shallower than `mlotst`.

3. Compute density from temperature and salinity with `compute_potential_density_anomaly` (TEOS-10), per model, per month, per level.
   - Note [cmip6-thetao-potential-temperature]: `thetao` is potential temperature referenced to the surface, so the calculation must follow the potential-temperature route (`temperature_kind()` reads this from the metadata); the in-situ route biases density increasingly with depth, and no archive carries `bigthetao`.
   - Note [cmip6-so-practical-salinity]: `so` stores practical-salinity numbers (about 35) despite the "0.001" units — do not multiply by 0.001 or 1000; convert S_P to S_A with the location-dependent function only at the TEOS-10 call that expects S_A.

4. Compute the operator MLD with `compute_mixed_layer_depth` from the density field, using a 0.03 kg m⁻³ threshold, `ref_depth` = each model's shallowest level, and the interpolated crossing described in step 2, for every monthly profile of every model.

def get_lat_lon(field, loc):
    if loc is None:
        return None, None
    lat_name = field.attrs.get('lat_coord', 'lat')
    lon_name = field.attrs.get('lon_coord', 'lon')
    if isinstance(loc, dict):
        # Case 1: the location already gives latitude/longitude values
        if (lat_name in loc and lon_name in loc
                and lat_name not in field.dims and lon_name not in field.dims):
            return float(loc[lat_name]), float(loc[lon_name])
        # Case 2: the location holds positional indices along the field's dims.
        # max_abs_error_at returns float-valued indices, which isel rejects,
        # so cast them to integers first.
        indexers = {k: int(round(float(v))) for k, v in loc.items() if k in field.dims}
        if indexers:
            point = field.isel(indexers)
            lat = point.coords[lat_name].values if lat_name in point.coords else point[lat_name].values
            lon = point.coords[lon_name].values if lon_name in point.coords else point[lon_name].values
            return float(lat), float(lon)
        # Case 3: label-based selection as a fallback
        point = field.sel({k: v for k, v in loc.items() if k in field.dims})
        lat = point.coords[lat_name].values if lat_name in point.coords else point[lat_name].values
        lon = point.coords[lon_name].values if lon_name in point.coords else point[lon_name].values
        return float(lat), float(lon)
    if isinstance(loc, tuple):
        indexers = {d: int(round(float(v))) for d, v in zip(field.dims, loc)}
        point = field.isel(indexers)
        lat = point.coords[lat_name].values if lat_name in point.coords else point[lat_name].values
        lon = point.coords[lon_name].values if lon_name in point.coords else point[lon_name].values
        return float(lat), float(lon)
    return None, None

    mlotst_clim = temporal_aggregate(data=mlotst, freq='climatology', op='mean')

    total_ocean_area = float(areacello.sum().compute())

    for month in months:

        mlotst_month = mlotst.where(mlotst.time.dt.month == month, drop=True)
        valid_mask = mld_op_month.notnull().all('time') & mlotst_month.notnull().all('time')

        mld_op_masked = mld_op_clim.sel(month=month).where(valid_mask)
        mlotst_masked = mlotst_clim.sel(month=month).where(valid_mask)

        metrics = compute_difference_metrics(data=mld_op_masked, reference=mlotst_masked, dim=None, weighting='area')
        bias = float(metrics['bias'])

        corr_res = analyze_correlation(var1=mld_op_masked, var2=mlotst_masked, dim=['lat', 'lon'], method='pearson')
