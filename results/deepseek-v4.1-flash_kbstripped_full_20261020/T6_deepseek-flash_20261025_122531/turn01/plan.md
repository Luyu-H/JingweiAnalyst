# Plan

1. Load the CMIP6 historical monthly `no3`, `areacello`, and the `thetao`/`so` needed for density for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR over 1971-01 to 2000-12 on their native grids with `load_regular_data`. Load WOA23 `nitrate` all-period annual climatology on the 1-degree grid with `load_climatology_data`; load WOA23 `landsea_01` (ocean > 1) with `load_landsea_mask`, `basinmask_01` with `load_basin_mask`, WOA cell areas with `load_areas`, and depth levels/boundaries for WOA23 and each model with `load_depth_levels`, keeping levels below 1000 m available.
- Note [missing-values-and-land-cells]: xarray decodes 1e20 to NaN; build each field’s valid mask from the field itself and mask the weights to the same cells; a value near 1e20 in any output is an unmasked fill value.
- Note [cmip6-grid-labels]: GFDL-ESM4 output is `gr`, already remapped to 1 degree with its own land-sea mask; CESM2 (~100 km) and MPI-ESM1-2-LR (~250 km) differ in resolution, so features narrower than the coarse grid are not comparable in amplitude.

2. Use `temporal_aggregate` to average each model’s monthly `no3` and `thetao`/`so` over 1971-2000 with day weights in that model’s calendar, producing 1971-2000 climatological mean fields. Use the WOA23 all-period annual nutrient climatology as loaded. Compute the nitracline after averaging the monthly fields, not as a mean of monthly nitraclines.
- Note [monthly-means-are-time-averages]: f(monthly mean) is not the mean of f; average-first-then-diagnostic is the like-for-like choice against WOA23, and the averaging must use `temporal_aggregate`, not `compute_basic_stat(op='mean', dim='time')`.

3. Using `load_depth_levels` to identify levels within the top 1000 m and the next deeper level, compute the nitracline with `compute_nutricline_depth` for each model’s 1971-2000 mean `no3` on its native grid and for WOA23 `nitrate` on the 1-degree grid. Search only levels within the top 1000 m, with the gradient at the deepest searched level using the level just below 1000 m. Keep native units and native grids for this diagnostic.
- Note [cmip6-bgc-units-per-volume]: compute the nitracline natively without unit conversion because it is scale-invariant; a constant density cancels exactly, while an in-situ density would shift the depth slightly. For Figure 2’s shared concentration unit, convert model `no3` from mol m-3 to µmol kg-1 using in-situ density from `compute_potential_density_anomaly` with `ref_pressure=None`, and report `attrs['density_assumption']`.

4. Compute the global area-weighted mean nitracline depth for each model on its native grid with `compute_basic_stat(op='area_weighted_mean')`, using its own `areacello` and valid field mask. For WOA23 use the WOA areas and the WOA `landsea_01` mask (ocean > 1). Report each mean to the nearest metre and each model’s difference from WOA23.
- Note [omip-weighted-means-and-integrals]: global and basin nitracline means must be area-weighted by `areacello` on the field’s own grid; an unweighted latitude mean is wrong; use `weighting='area'` in `analyze_correlation` and the area-weighted default of `compute_difference_metrics` on the shared mask.
- Note [omip-native-grid-vs-regridded]: compute each model’s global and basin mean nitracline on its own native grid with its own `areacello`; regrid to the WOA 1-degree grid only for maps, pattern correlation and RMSE, using `'conservative'` going coarser for continuous fields and `'nearest_s2d'` for the categorical basin mask; the nitracline is an extremum depth quantised by the vertical grid, so read the maps together with the gradient and use `regrid_vertical` for the fixed-depth Figure 2 section rather than selecting the nearest level.

5. Regrid the categorical WOA23 `basinmask_01` to each model’s native grid with `regrid_horizontal(method='nearest_s2d')` where needed, then use `select_basin` with `include_marginal_seas=True` and `depth_dependent=False` to isolate the Pacific, Atlantic and Indian Oceans. Compute the area-weighted mean nitracline in each basin for each model on its native grid with its native `areacello`; compute WOA23 basin means on the 1-degree grid with WOA areas and the WOA land-sea mask. Report basin means to the nearest metre and model-minus-WOA23 differences, and check whether each model reproduces WOA23’s ordering of the three basin depths.
- Note [basin-and-region-definitions]: basin means use the WOA23 mask via `load_basin_mask`/`select_basin` with `include_marginal_seas=True` and `depth_dependent=False`; state that the WOA23 basin mask was used and that Southern and Arctic are excluded; marginal-sea folding changes basin means, so report that choice with the basin numbers.

6. Regrid each model nitracline field to the WOA 1-degree grid with `regrid_horizontal(method='conservative')` and apply the WOA23 land-sea mask (ocean > 1). Build one shared valid-data mask over all four nitracline fields with `build_comparison_mask` (`ocean_only=True` default) and apply `.where(mask)` to every field before the correlation/RMSE. Record the mask cell counts.
- Note [common-comparison-mask]: build one shared valid-data mask over all four nitracline fields with `build_comparison_mask` and apply `.where(mask)` to every field before the correlation/RMSE; do not score each model on its own pairwise mask; `ocean_only=True` is correct because WOA23 is the reference; report the cell counts the mask records alongside the metrics.

7. On the shared mask, compute each model’s spatial Pearson correlation with WOA23 using `analyze_correlation` with `weighting='area'`, reported to 3 decimal places, and the RMSE in metres using `compute_difference_metrics`, reported to 1 decimal place. Use the [omip-weighted-means-and-integrals] weighting and the [common-comparison-mask] shared mask, and combine the correlation, RMSE and bias to identify which model reproduces the observed nitracline best.

8. Figure 1: make a 2-by-2 panel of global maps of nitracline depth for WOA23, CESM2, GFDL-ESM4 and MPI-ESM1-2-LR on the WOA 1-degree grid, using one shared sequential colour scale on which deeper is visually heavier.
Figure 2: for each source, select the equatorial Pacific section 120°E–80°W and 2°S–2°N, average over latitude with `compute_basic_stat` using spatial weighting, regrid horizontally to the WOA 1-degree grid with `regrid_horizontal(method='conservative')`, and regrid vertically to WOA depth levels with `regrid_vertical` rather than selecting the nearest level. For the models, convert nitrate to µmol kg-1 with the [cmip6-bgc-units-per-volume] density conversion; WOA23 remains in µmol kg-1. Plot four panels in the order WOA23, CESM2, GFDL-ESM4, MPI-ESM1-2-LR, covering 120°E–80°W and the top 1000 m with depth increasing downward, on one shared colour scale in µmol kg-1, and overlay each panel’s own nitracline depth along the section computed with `compute_nutricline_depth` under the top-1000 m rule.
