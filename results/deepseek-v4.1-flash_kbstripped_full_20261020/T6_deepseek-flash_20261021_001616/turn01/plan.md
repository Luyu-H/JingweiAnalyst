# Plan

1. Load the WOA23 reference fields on the 1-degree grid: `load_climatology_data` for `woa23` `nitrate`, all-period annual climatology; `load_landsea_mask` for `landsea_01` and keep ocean where value > 1; `load_basin_mask` for `basinmask_01`; `load_areas` for WOA grid-cell areas; `load_depth_levels` for WOA levels and layer boundaries. Apply the WOA land-sea mask to WOA nitrate.
2. Load CMIP6 historical `no3`, `thetao` and `so` for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR with `load_regular_data`, monthly over 1971-01 to 2000-12, each on its native grid; load each model’s native `areacello` with `load_areas` and its depth levels with `load_depth_levels`.
   - Note [missing-values-and-land-cells]: apply CF masking so the CMIP6 missing value 1e20 for land and below-sea-floor cells is removed before any mean, sum or comparison; do not let raw arrays, scale/offset-before-mask or float32 overflow turn these into huge values.
   - Note [cmip6-grid-labels]: GFDL-ESM4 is `gr`, so its values, land-sea mask and `volcello` are already remapped (conserve_order1, 75→35 z levels); its “native-grid” numbers are archive-grid numbers and its budgets are only approximately conservative. Resolution differs by about 2.5× (CESM2 ~100 km, MPI ~250 km), so narrow features are not comparable in amplitude.
3. Convert each model’s monthly `no3` from mol m-3 to µmol kg-1: compute in-situ density with `compute_potential_density_anomaly` from monthly `thetao` and `so` using `ref_pressure=None` (forming density from the returned sigma), convert `no3` from mol m-3 to µmol m-3 with `transform_unit`, then divide by density with `compute_ratio` to obtain µmol kg-1; preserve the density assumption on the fields.
   - Note [cmip6-bgc-units-per-volume]: model `no3` is mol m-3 and WOA23 is µmol kg-1, so use the in-situ-density conversion and state `attrs['density_assumption']`; the nitracline depth is invariant to a constant density but a depth-varying in-situ density shifts it slightly, so locate the depth on the native basis and say so.
4. Build the 1971-2000 model mean nitrate fields with `temporal_aggregate(freq='mean')`, so months carry calendar-length weights. Use the WOA23 all-period annual climatology as already loaded.
   - Note [monthly-means-are-time-averages]: average nitrate first and then locate the maximum gradient, which is the like-for-like choice against the WOA23 climatology; use `temporal_aggregate(freq='mean')` for the model 1971-2000 mean rather than an equal-month `compute_basic_stat(op='mean', dim='time')`.
5. Compute nitracline depth for WOA23 and each model on its native grid with `compute_nutricline_depth`: search levels within the top 1000 m only, and for the deepest selected level use the level just below 1000 m by loading the profile below 1000 m.
   - Note [omip-native-grid-vs-regridded]: compute global and basin mean nitracline depths on each source’s own grid with its own `areacello`; regrid to the WOA 1-degree grid only for the maps, the pattern correlation and the RMSE, stating “conservative” where coarsening. The nitracline is a vertical-extremum diagnostic quantised by each source’s vertical grid, so read the maps alongside the gradient and note that depth resolution differs between products.
6. Compute global and basin mean nitracline depths with `compute_basic_stat(op='area_weighted_mean')`, using each source’s own `areacello` masked to the same valid nitracline cells. For basins, use the WOA23 `basinmask_01` via `load_basin_mask` and `select_basin`, keeping Pacific, Atlantic and Indian Oceans and excluding Southern and Arctic Oceans. Compute each model-minus-WOA23 difference globally and in each basin.
   - Note [basin-and-region-definitions]: basin means must come from the single WOA23 `basinmask_01` definition for all four sources, with `include_marginal_seas=True` and `depth_dependent=False`; state that the OMIP 10-region `basin` mask is not used.
   - Note [omip-weighted-means-and-integrals]: every global and basin mean must be area-weighted with `compute_basic_stat(op='area_weighted_mean')` and `areacello` masked to the same valid cells; unweighted means on curvilinear grids are wrong. The map-to-map Pearson correlation uses `analyze_correlation(weighting='area')`, and `compute_difference_metrics` weights by area by default.
7. Regrid the four nitracline fields to the WOA23 1-degree grid with `regrid_horizontal`, using conservative coarsening. Build one shared comparison mask with `build_comparison_mask` (`ocean_only=True`, the default) and apply `.where(mask)` to every field before scoring. For each model against WOA23, compute the Pearson correlation with `analyze_correlation(weighting='area')` and the RMSE with `compute_difference_metrics`; report the mask cell count and quote `mean_data`/`mean_reference` over the shared sample. Compare basin rankings from step 6 with WOA23’s Pacific/Atlantic/Indian ordering, and identify the best model from the shared-mask correlation and RMSE.
   - Note [common-comparison-mask]: regrid all four nitracline fields to the WOA23 1-degree grid, build one mask with `build_comparison_mask` and apply `.where(mask)` to every field before the Pearson correlation and RMSE; `ocean_only=True` is correct here, and report the cell counts the mask records beside the metrics and use the shared-sample `mean_data`/`mean_reference` from `compute_difference_metrics`.
8. Figure 1: using the regridded nitracline fields, draw a 2-by-2 panel of global maps for CESM2, GFDL-ESM4, MPI-ESM1-2-LR and WOA23 on one shared sequential colour scale with deeper values visually heavier/darker. Use plotting code for the figure because no plotting tool is provided.
9. Figure 2: subset WOA23 and each model to the equatorial Pacific longitude range 120°E–80°W and 2°S–2°N, using the 1971-2000 model mean fields and the WOA23 annual climatology. Average concentration over 2°S–2°N with `compute_basic_stat(op='area_weighted_mean', dim='latitude')`, then compute the nitracline on each averaged longitude–depth section with `compute_nutricline_depth`, again using the level below 1000 m for the deepest gradient. Plot four panels in the order WOA23, CESM2, GFDL-ESM4, MPI-ESM1-2-LR, over 120°E–80°W and the top 1000 m with depth increasing downward, on one shared colour scale in µmol kg-1, with each panel’s own nitracline depth overlaid as a line.

Other notes:
- The nitracline is defined here as the depth of the maximum vertical gradient of nitrate concentration searched within the top 1000 m, with the deepest gradient using the level just below 1000 m.
- Keep all intermediate fields unrounded; round only the reported global/basin means, differences, correlations and RMSE to the requested precision.
- Global and basin means use each source’s native grid and native `areacello`; maps, pattern correlations and RMSE use the common WOA23 1-degree grid with conservative regridding.
- WOA23 nitrate is the reference in µmol kg-1; model nitrate is converted to the same concentration unit before absolute comparisons and before Figure 2.
- Determine the best model from the shared-mask Pearson correlation and RMSE, and check the three-basin ordering against the WOA23 ordering rather than against a model-derived ordering.
