# Plan

1. Load inputs with `load_regular_data`: ERSSTv5 monthly `sst` over 1950-01 to 2014-12 on its native 2-degree grid, and CMIP6 historical monthly `tos` over the same 780 months for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR. Use `load_areas` to obtain each CMIP6 model’s published `areacello` and the ERSSTv5 native 2-degree cell areas, masking to cells where that source’s `tos`/`sst` is valid; record `area_source` and the total valid area within 5S-5N, 170W-120W for each source.
- Note [cmip6-static-grid-fields]: use each model’s published `areacello` for its own weights; do not rescale one model to another; report the area over which each Nino3.4 regional mean is taken.
- Note [cmip6-grid-labels]: GFDL-ESM4 is on a 180x360 remapped grid, while CESM2 and MPI-ESM1-2-LR are native grids differing in resolution by about a factor of 2.5, so amplitude differences partly reflect resolution.
- Note [cmip6-tos-bulk-top-cell]: `tos` is the bulk temperature of each model’s top cell, including under-ice values near freezing, and the top cells differ in depth (CESM2 0–10 m, GFDL-ESM4 0–2 m, MPI-ESM1-2-LR 0–12 m), so the compared amplitudes are not for the same layer depth.

2. Build the four monthly Nino3.4 anomaly series. For ERSSTv5 and each CMIP6 model separately, use `compute_enso_nino_index` for the Nino3.4 region 5S-5N, 170W-120W over 1950-01 to 2014-12, with each source’s own valid-grid area weights and with the climatology set to that source’s own monthly climatology over 1950–2014, not WOA23. This gives, for each source, a 780-month anomaly series relative to its own Jan–Dec monthly climatology. The equivalent low-level area-weighted regional mean is `compute_basic_stat` with `op='area_weighted_mean'`.
- Note [anomaly-baselines-and-climate-indices]: build each index as the source’s own regional mean minus its own monthly climatology over 1950–2014, matched by calendar month; state the 1950–2014 baseline with the result; do not use `climatology='woa23'` for model output; all amplitude statistics use calendar months Jan–Dec, not DJF/MAM season means.
- Note [omip-weighted-means-and-integrals]: the 5S-5N, 170W-120W mean must be area-weighted with the model’s own `areacello` restricted to valid `tos` cells using NaN-aware weights, and the ERSSTv5 mean likewise area-weighted on its own 2-degree grid; the equivalent operator is `compute_basic_stat` with `op='area_weighted_mean'`, not an unweighted or latitude-weighted mean.
- Note [monthly-means-are-time-averages]: the monthly climatology is the plain mean of that calendar month’s values over 1950–2014, with no day weights; day weights apply only to averages spanning different calendar months. Variance within a month cannot be recovered from monthly means, so the 780-month std is inter-month/interannual only.

3. For each of the four 780-month Nino3.4 anomaly series, compute the population standard deviation with ddof=0 over all months and report it to 2 decimal places. Compute each model’s amplitude bias as model std minus ERSSTv5 std and amplitude ratio as model std divided by ERSSTv5 std, both to 2 decimal places, then rank the three models from smallest to largest absolute amplitude bias.
- Note [cmip6-experiments-historical-ssp245]: each historical run has one member and its own internal variability; compare the amplitude statistics (total std, calendar-month std and exceedance counts), not individual years or event timing, with ERSSTv5.

4. For each source, group the 780 anomaly values by calendar month (Jan–Dec, 65 values per month) and compute the population standard deviation with ddof=0 for each month, giving 48 values reported to 2 decimal places. For each source, identify the calendar month of maximum std and its value, the month of minimum std, and the maximum-to-minimum ratio to 2 decimal places. Compare each model’s peak month and phase-locking strength with ERSSTv5’s observed peak month and value, using the [monthly-means-are-time-averages] grouping convention.

5. For each source, count the number of months whose Nino3.4 anomaly has absolute value strictly greater than 1.0 degrees Celsius; compute the percentage as count divided by 780 times 100, reported to 1 decimal place.

6. Produce Figure 1 as a line plot of the 12 calendar-month standard deviations versus calendar month (January to December), with all four sources on one axis, ERSSTv5 visually distinct from the three models, and each curve’s peak month marked. Produce Figure 2 as four vertically stacked panels in the order ERSSTv5, CESM2, GFDL-ESM4, MPI-ESM1-2-LR, sharing one 1950–2014 time axis and an identical y-axis range covering every anomaly series, with the +1.0 and -1.0 degrees Celsius levels marked and each panel annotated with that source’s all-month standard deviation and exceedance percentage.

Other notes:
- No horizontal regridding or common spatial mask is applied to the fields; each index is computed on its own native grid and only the resulting monthly series are compared.
- The comparison is limited to ERSSTv5 and the three CMIP6 historical single members over 1950–2014; no ssp245, cpc_indices or WOA23 climatology is used.
- Values are rounded only for reporting at the requested precision; rankings and ratios use unrounded intermediate values.
