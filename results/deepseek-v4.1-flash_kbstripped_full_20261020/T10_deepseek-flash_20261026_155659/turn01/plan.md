   - Note [monthly-means-are-time-averages]: Form the threshold, thickness and AOU diagnostics on the period-mean fields (average-first), using temporal_aggregate day weights in the model calendar; WOA23 is already a time-mean normal. State this average-first choice in the answer.

For threshold work only, compute in-situ density from each model/experiment period-mean thetao and so with compute_potential_density_anomaly(ref_pressure=None), converting sigma to density by adding 1000 kg m-3 if the tool returns sigma, then use transform_unit to convert period-mean o2 from mol m-3 to micromoles per kilogram with that density.    - Note [cmip6-bgc-units-per-volume]: Use in-situ density from compute_potential_density_anomaly(ref_pressure=None) in the o2 unit conversion and state attrs['density_assumption']; for the global oxygen inventory use native mol m-3 with convert_concentration_to_content, not a 1000-times micromoles-per-kilogram relabel.

   - Note [common-comparison-mask]: Use one build_comparison_mask mask with ocean_only=True for all multi-source metrics and apply .where(mask) to every field; report the mask cell counts alongside the comparison metrics.

Use identify_oxygen_minimum_zone at the 60 threshold with load_depth_levels boundaries to produce column OMZ thickness maps for the same six sources, and locate_extreme to report each maximum thickness with its latitude and longitude. Report volumes in 1e15 m3 to 3 significant figures and maximum thickness to 1 decimal place with latitude/longitude to 2 decimal places.
   - Note [missing-values-and-land-cells]: Use NaN-aware reductions and build each variable's valid mask from that variable; treat 1e20 and 9.97e36 as missing, and let compute_exceedance_fraction keep land out of both numerator and denominator rather than testing a threshold on NaNs by hand.

Where a model is not on the WOA grid, use the common 1-degree regridded oxygen/volume fields from step 4 so the WOA basin labels are applied consistently. Report each basin volume in 1e15 m3 to 3 significant figures.
   - Note [basin-and-region-definitions]: Use the WOA23 basin mask via select_basin/load_basin_mask with include_marginal_seas=True and depth_dependent=False for named oceans; state that these are WOA basin labels, not the OMIP 10-region mask.

Report each to 1 decimal place and interpret: a high mean AOU together with low percent saturation indicates respiration has consumed the oxygen, rather than the zone being set only by poor ventilation.
