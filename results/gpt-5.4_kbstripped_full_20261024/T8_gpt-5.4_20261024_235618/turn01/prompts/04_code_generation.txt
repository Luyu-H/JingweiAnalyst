Important:
- Computation code MUST be complete and standalone
- Let failures raise. Do NOT wrap a step in try/except to record the error and carry on: the run
  then exits cleanly with part of the answer silently missing, and the repair pass never sees the
  problem. If one model or one variable cannot be processed the way you wrote it, the right
  response is to fix the call, not to catch the exception. Only catch one when the question itself
  asks you to tolerate a missing input, and then still leave the failure in a variable the answer
  can report.
- The loaders return LAZY (dask-backed) xr.DataArray objects. Every quantity you want reported must
  be materialised explicitly with .compute() (or float()) into its own small variable, otherwise the
  downstream step sees a dask placeholder and no numbers at all. Large intermediates can stay lazy.
- For regional or global means use compute_basic_stat with its weighted operators
  (area_weighted_mean / volume_weighted_mean). Do not average over lat/lon with a plain .mean(), and
  do not fetch areacello by hand.
- CESM2 and MPI-ESM1-2-LR are on curvilinear grids: their index dimensions (nlat/nlon, j/i) are NOT
  geographic and cannot be sliced by value with .sel(). Subset them through the loader's lat_range /
  lon_range arguments instead.
- CMIP6 concentrations are in mol m-3 (volume basis) while WOA23 and GLODAP are in umol kg-1 (mass
  basis); convert with transform_unit before comparing them.
- For a region that crosses the dateline (the equatorial Pacific, 120E-280E), just pass lon_range to
  the loading tool: it returns a continuous longitude axis that the weighted statistics and
  derived-quantity tools accept as it is. Do not assemble such a region by hand with %360, by
  concatenating two sel windows, or by sortby — an array rebuilt that way has left the dataset's own
  grid, and weighting it fails with "these lon values have no cell on the dataset's own grid".
- Arrays from the loaders carry provenance attributes (source_dataset, grid_type, ...) that the
  weighted statistics and derived-quantity tools use to find the right grid. The execution
  environment runs with keep_attrs enabled, so ordinary xarray operations preserve them; but when a
  step changes the physical quantity (a ratio, a difference of unlike things), set the new units
  yourself with .assign_attrs(units=...), or the reported units will be wrong.
- Visualization code can reference variables from computation
- Colour limits on a shared scale: take them from a robust percentile of the pooled data, e.g.
  `vmax = float(np.nanpercentile(np.abs(np.concatenate([...])), 98))`, and never from the maximum
  absolute value. A single coastal or marginal-sea cell is routinely an order of magnitude larger
  than the signal, and `vmax = nanmax(abs(...))` then hands the whole scale to that one cell so
  every panel renders as uniform white. Use a diverging map centred on zero for a difference or
  anomaly and a sequential map for a magnitude. When values are clipped, pass `extend='both'` (or
  'max'/'min') so the colourbar shows arrows, and say how they were clipped in the figure title.
- Keep a colourbar label to the quantity and its units, e.g. "SSS bias (psu)", under about 40
  characters. A vertical colourbar label longer than the bar is cut off at both ends in the saved
  image. Notes such as the clipping percentile, "shared scale" or the data source go in the figure
  or panel title, never in the colourbar label.
- Do NOT call tight_layout() after attaching a colorbar to several axes (`fig.colorbar(..., ax=axes)`)
  — it does not know about that colorbar and will lay the panels over it. Either build the figure
  with `plt.subplots(..., constrained_layout=True)` and add no tight_layout at all, or call
  tight_layout BEFORE adding the colorbar.
- Keep annotation off the data: `loc="best"` for a legend, or place it outside the axes. A legend
  pinned to a corner where a curve peaks hides the very feature the panel is there to show.
- A field on a curvilinear grid has 2-D coordinates that are NOT called lat/lon. Read the names off

        "talk": temporal_aggregate(talk_2002, freq="mean", op="mean"),
        "ph": temporal_aggregate(ph_2002, freq="mean", op="mean"),
        "thetao": temporal_aggregate(thetao_2002, freq="mean", op="mean"),
        "so": temporal_aggregate(so_2002, freq="mean", op="mean"),
    }
    model_means_hist[model] = {
        "dissic": temporal_aggregate(dissic_hist, freq="mean", op="mean"),
        "thetao": temporal_aggregate(thetao_hist, freq="mean", op="mean"),
        "so": temporal_aggregate(so_hist, freq="mean", op="mean"),
    }

    # In-situ density anomaly for unit conversion
    model_density_2002[model] = compute_potential_density_anomaly(
        temp_data=model_means_2002[model]["thetao"],
        sal_data=model_means_2002[model]["so"],
        ref_pressure=None,
    )
    model_density_hist[model] = compute_potential_density_anomaly(
        temp_data=model_means_hist[model]["thetao"],
        sal_data=model_means_hist[model]["so"],
        ref_pressure=None,
    )

    # Convert to umol kg-1
    model_converted_2002[model] = {
        "dissic": transform_unit(
            model_means_2002[model]["dissic"],
            from_unit=model_means_2002[model]["dissic"].attrs.get("units", "mol m-3"),
            to_unit="umol kg-1",
            density=model_density_2002[model],
        ),
        "talk": transform_unit(
            model_means_2002[model]["talk"],
            from_unit=model_means_2002[model]["talk"].attrs.get("units", "mol m-3"),
            to_unit="umol kg-1",
            density=model_density_2002[model],
        ),
        "ph": model_means_2002[model]["ph"],
    }
    model_converted_hist[model] = {
        "dissic": transform_unit(
            model_means_hist[model]["dissic"],
            from_unit=model_means_hist[model]["dissic"].attrs.get("units", "mol m-3"),
            to_unit="umol kg-1",
            density=model_density_hist[model],
        ),
    }

    # Native-grid 0-50 m scalar means
    model_dic_0_50_mean = compute_basic_stat(
        model_converted_2002[model]["dissic"].sel(depth=slice(depth_0_50[0], depth_0_50[1])),
        op="volume_weighted_mean",
    ).compute()
    model_talk_0_50_mean = compute_basic_stat(
        model_converted_2002[model]["talk"].sel(depth=slice(depth_0_50[0], depth_0_50[1])),
        op="volume_weighted_mean",
    ).compute()
    model_ph_0_50_mean = compute_basic_stat(
        model_converted_2002[model]["ph"].sel(depth=slice(depth_0_50[0], depth_0_50[1])),
        op="volume_weighted_mean",
    ).compute()
    model_dic_hist_0_50_mean = compute_basic_stat(
        model_converted_hist[model]["dissic"].sel(depth=slice(depth_0_50[0], depth_0_50[1])),
        op="volume_weighted_mean",
    ).compute()

    dic_diff = float(model_dic_0_50_mean.values) - glodap_scalar_means["dic_0_50_mean_umolkg"]
    talk_diff = float(model_talk_0_50_mean.values) - glodap_scalar_means["talk_0_50_mean_umolkg"]
    ph_diff = float(model_ph_0_50_mean.values) - glodap_scalar_means["ph_0_50_mean_total"]
    dic_change = float(model_dic_0_50_mean.values) - float(model_dic_hist_0_50_mean.values)
    dic_change_ratio = dic_change / dic_diff

    model_scalar_means[model] = {
        "dic_0_50_mean_umolkg": float(model_dic_0_50_mean.values),
        "dic_minus_glodap_umolkg": float(dic_diff),
        "talk_0_50_mean_umolkg": float(model_talk_0_50_mean.values),
        "talk_minus_glodap_umolkg": float(talk_diff),
        "ph_0_50_mean_total": float(model_ph_0_50_mean.values),
        "ph_minus_glodap": float(ph_diff),
        "dic_1971_2000_0_50_mean_umolkg": float(model_dic_hist_0_50_mean.values),
        "dic_change_2002_minus_1971_2000_umolkg": float(dic_change),
        "dic_change_to_glodap_bias_ratio": float(dic_change_ratio),
    }

    # Native-grid 0-50 m DIC map
    model_0_50_maps_native[model] = compute_basic_stat(
        model_converted_2002[model]["dissic"].sel(depth=slice(depth_0_50[0], depth_0_50[1])),
        op="mean",
        dim="depth",
    ).assign_attrs(units="umol kg-1")

    # Regrid model 0-50 m DIC maps to GLODAP grid
    model_0_50_maps_regridded[model] = regrid_horizontal(
        model_0_50_maps_native[model],
        target=glodap_dic_0_50_map,
        method="conservative",
        skipna=True,
        na_thres=0.5,
    )

# Shared comparison mask across GLODAP + all three regridded models
shared_mask = build_comparison_mask(
    fields=[glodap_dic_0_50_map] + [model_0_50_maps_regridded[m] for m in models],
    ocean_only=False,
    reduce_other_dims="all",
).compute()

masked_glodap_dic_0_50_map = glodap_dic_0_50_map.where(shared_mask)

# Map metrics and bias maps
map_metrics = {}
dic_bias_maps = {}

for model in models:
    masked_model_map = model_0_50_maps_regridded[model].where(shared_mask)
    metrics = compute_difference_metrics(
        data=masked_model_map,
        reference=masked_glodap_dic_0_50_map,
        dim=None,
        weighting="auto",
    )
    corr = analyze_correlation(
        var1=masked_model_map,
        var2=masked_glodap_dic_0_50_map,
        dim=["lat", "lon"],
        method="pearson",
        weighting="area",
        min_periods=10,
    )

    mean_bias = float(metrics["bias"].compute().values if hasattr(metrics["bias"], "compute") else metrics["bias"])
    rmse = float(metrics["rmse"].compute().values if hasattr(metrics["rmse"], "compute") else metrics["rmse"])
    spatial_corr = float(corr["correlation"].compute().values)

    map_metrics[model] = {
        "mean_bias_umolkg": mean_bias,
        "rmse_umolkg": rmse,
        "spatial_correlation": spatial_corr,
        "n_valid": int(metrics["n_valid"]),
        "weighting": metrics["weighting"],
    }

    dic_bias_maps[model] = metrics["difference"].compute().assign_attrs(units="umol kg-1")

# Depthwise DIC bias comparison on GLODAP grid
for model in models:
    model_dic_depths = regrid_vertical(
        model_converted_2002[model]["dissic"],
        target=target_depths,
        method="linear",
        fill_surface=True,
    )
    model_dic_depths_rg = regrid_horizontal(
        model_dic_depths,
        target=glodap_tco2_depths,
        method="conservative",
        skipna=True,
        na_thres=0.5,
    )

    depth_bias = {}
    for depth_val in target_depths:
        model_slice = model_dic_depths_rg.sel(depth=depth_val)
        glodap_slice = glodap_tco2_depths.sel(depth=depth_val)

        metrics_depth = compute_difference_metrics(
            data=model_slice,
            reference=glodap_slice,
            dim=None,
            weighting="auto",
        )
        depth_bias[depth_val] = float(
            metrics_depth["bias"].compute().values
            if hasattr(metrics_depth["bias"], "compute")
            else metrics_depth["bias"]
        )

    depth_bias_profiles[model] = depth_bias
