Important:
- Computation code MUST be complete and standalone
- Let failures raise. Do NOT wrap a step in try/except to record the error and carry on: the run
  then exits cleanly with part of the answer silently missing, and the repair pass never sees the
  problem. If one model or one variable cannot be processed the way you wrote it, the right
  response is to fix the call, not to catch the exception. Only catch one when the question itself
  asks you to tolerate a missing input, and then still leave the failure in a variable the answer
  can report.
- The loaders return LAZY (dask-backed) xr.DataArray objects. Every quantity you want reported must
  be materialised explicitly with .compute() (or float()) into its own small variable, otherwise the
  downstream step sees a dask placeholder and no numbers at all. Large intermediates can stay lazy.
- For regional or global means use compute_basic_stat with its weighted operators
  (area_weighted_mean / volume_weighted_mean). Do not average over lat/lon with a plain .mean(), and
  do not fetch areacello by hand.
- CESM2 and MPI-ESM1-2-LR are on curvilinear grids: their index dimensions (nlat/nlon, j/i) are NOT
  geographic and cannot be sliced by value with .sel(). Subset them through the loader's lat_range /
  lon_range arguments instead.
- CMIP6 concentrations are in mol m-3 (volume basis) while WOA23 and GLODAP are in umol kg-1 (mass
  basis); convert with transform_unit before comparing them.
- For a region that crosses the dateline (the equatorial Pacific, 120E-280E), just pass lon_range to
  the loading tool: it returns a continuous longitude axis that the weighted statistics and
  derived-quantity tools accept as it is. Do not assemble such a region by hand with %360, by
  concatenating two sel windows, or by sortby — an array rebuilt that way has left the dataset's own
  grid, and weighting it fails with "these lon values have no cell on the dataset's own grid".
- Arrays from the loaders carry provenance attributes (source_dataset, grid_type, ...) that the
  weighted statistics and derived-quantity tools use to find the right grid. The execution
  environment runs with keep_attrs enabled, so ordinary xarray operations preserve them; but when a
  step changes the physical quantity (a ratio, a difference of unlike things), set the new units
  yourself with .assign_attrs(units=...), or the reported units will be wrong.
- Visualization code can reference variables from computation
- Colour limits on a shared scale: take them from a robust percentile of the pooled data, e.g.
  `vmax = float(np.nanpercentile(np.abs(np.concatenate([...])), 98))`, and never from the maximum
  absolute value. A single coastal or marginal-sea cell is routinely an order of magnitude larger
  than the signal, and `vmax = nanmax(abs(...))` then hands the whole scale to that one cell so
  every panel renders as uniform white. Use a diverging map centred on zero for a difference or
  anomaly and a sequential map for a magnitude. When values are clipped, pass `extend='both'` (or
  'max'/'min') so the colourbar shows arrows, and say how they were clipped in the figure title.
- Keep a colourbar label to the quantity and its units, e.g. "SSS bias (psu)", under about 40

  image. Notes such as the clipping percentile, "shared scale" or the data source go in the figure
  or panel title, never in the colourbar label.
- Do NOT call tight_layout() after attaching a colorbar to several axes (`fig.colorbar(..., ax=axes)`)
  — it does not know about that colorbar and will lay the panels over it. Either build the figure
  with `plt.subplots(..., constrained_layout=True)` and add no tight_layout at all, or call
  tight_layout BEFORE adding the colorbar.
- Keep annotation off the data: `loc="best"` for a legend, or place it outside the axes. A legend

# PDO assessment: three CMIP6 models vs ERSSTv5, 1950-01 to 2014-12
# ---------------------------------------------------------------------------
time_range  = ["1950-01", "2014-12"]
base_period = ["1950-01", "2014-12"]
models = ["CESM2", "GFDL-ESM4", "MPI-ESM1-2-LR"]
order  = ["ERSSTv5"] + models

# ---- 1. load the GLOBAL SST fields (compute_pdo_index needs global coverage
#         because it removes the global-mean anomaly itself) -----------------
raw = {}
raw["ERSSTv5"] = load_regular_data(dataset="ersst", variable="sst",
                                   time_range=time_range)
for m in models:
    raw[m] = load_regular_data(dataset="cmip6_historical", variable="tos",
                               model=m, time_range=time_range)

# ---- 2. bilinear regridding onto the common 1-degree grid -----------------
sst_1deg = {k: regrid_horizontal(v, target="1deg", method="bilinear")
            for k, v in raw.items()}

# ---- 3. monthly anomalies vs each source's own 1950-2014 climatology ------
sst_anom = {k: compute_anomaly_vs_own_climatology(v, freq="month",
                                                  base_period=base_period)
            for k, v in sst_1deg.items()}

# ---- 4. leading North Pacific mode (tool cuts 20N-70N, 110E-100W itself) --
pdo_index, eof_pattern, explained_variance, regression_pattern = {}, {}, {}, {}
for k in order:
    idx, eof, ev, reg = compute_pdo_index(sst_anom[k])
    pdo_index[k]          = idx.compute()
    eof_pattern[k]        = eof.compute()
    explained_variance[k] = float(np.asarray(ev).ravel()[0])
    regression_pattern[k] = reg.compute()

# ---- 5. amplitude of the mode (deg C per standard deviation of the index) --
amplitude     = {}
amplitude_rms = {}
for k in order:
    v = np.asarray(regression_pattern[k].values, dtype=float)
    amplitude[k]     = float(np.nanmax(np.abs(v)))          # peak amplitude
    amplitude_rms[k] = float(np.sqrt(np.nanmean(v ** 2)))   # domain RMS

# ---- 6. lag-1-year (12-month) autocorrelation of each standardized index --
lag12_autocorr = {}
lag12_pvalue   = {}
for k in order:
    r = analyze_correlation(pdo_index[k], pdo_index[k], dim="time", lag=12)
    lag12_autocorr[k] = float(np.asarray(r["correlation"]).ravel()[0])
    lag12_pvalue[k]   = float(np.asarray(r["pvalue"]).ravel()[0])

# ---- 7. published NOAA/NCEI PDO index and its agreement with ERSSTv5 ------
pdo_published = load_regular_data(dataset="cpc_indices", variable="pdo",
                                  product="pdo", time_range=time_range)
pdo_published = pdo_published.squeeze().compute()

_r = analyze_correlation(pdo_index["ERSSTv5"], pdo_published, dim="time")
corr_published        = float(np.asarray(_r["correlation"]).ravel()[0])
corr_published_pvalue = float(np.asarray(_r["pvalue"]).ravel()[0])
corr_published_n      = int(np.asarray(_r["n_samples"]).ravel()[0])

# ---- 8. spatial (area weighted) pattern correlation vs ERSSTv5 ------------
pattern_corr, pattern_corr_p = {}, {}
for m in models:
    r = analyze_correlation(regression_pattern["ERSSTv5"], regression_pattern[m],
                            dim=["lat", "lon"], method="pearson",
                            weighting="area")
    pattern_corr[m]   = float(np.asarray(r["correlation"]).ravel()[0])
    pattern_corr_p[m] = float(np.asarray(r["pvalue"]).ravel()[0])

# ---- 9. 9-year (108-month) centred running mean of the ERSSTv5 index ------
smoothed_ersst = temporal_aggregate(pdo_index["ERSSTv5"], freq="rolling",
                                    op="mean", window=108, center=True).compute()
sv = np.asarray(smoothed_ersst.values, dtype=float)
st = pd.to_datetime(np.asarray(smoothed_ersst["time"].values))
sg = np.sign(sv)

crossings = []
for i in range(1, len(sv)):
    if not np.isfinite(sv[i]) or not np.isfinite(sv[i - 1]):
        continue
    if sg[i] == 0 or sg[i - 1] == 0:
        continue
    if sg[i] != sg[i - 1]:
        crossings.append(int(st[i].year))

# merge crossings less than 3 years after the last counted transition
transitions = []
for y in crossings:
    if (not transitions) or (y - transitions[-1] >= 3):
        transitions.append(y)

# documented Pacific climate shifts over 1950-2014
documented_shifts = {"1976/77": (1976, 1977),
                     "1988/89": (1988, 1989),
                     "1998/99": (1998, 1999)}
shift_match = {}
for name, yrs in documented_shifts.items():
    shift_match[name] = [y for y in transitions
                         if min(abs(y - yrs[0]), abs(y - yrs[1])) <= 1]

# ---- 10. summary tables ---------------------------------------------------
summary = pd.DataFrame({
    "explained_variance_pct": {k: round(explained_variance[k], 1) for k in order},
    "amplitude_degC_per_SD":  {k: round(amplitude[k], 3)         for k in order},
    "amplitude_RMS_degC_SD":  {k: round(amplitude_rms[k], 3)     for k in order},
    "lag12_autocorr":         {k: round(lag12_autocorr[k], 3)    for k in order},
})
summary.loc[[m for m in models], "pattern_corr_vs_ERSSTv5"] = \
    [round(pattern_corr[m], 3) for m in models]

best_model = max(models, key=lambda m: pattern_corr[m])

print(summary.to_string())
print()
print(f"ERSSTv5 index vs published NOAA PDO : r = {corr_published:.3f} "
      f"(p = {corr_published_pvalue:.3g}, n = {corr_published_n})")
print(f"PDO phase-transition years (108-month running mean) : {transitions}")
print(f"Matched documented shifts : {shift_match}")
print(f"Best pattern reproduction : {best_model} "
      f"(r = {pattern_corr[best_model]:.3f})")
