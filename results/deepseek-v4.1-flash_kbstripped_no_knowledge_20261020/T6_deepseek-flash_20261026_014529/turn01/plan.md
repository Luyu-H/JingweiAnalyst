# Plan

1. Load WOA23 nitrate as the all-time-period annual climatology on the 1-degree grid, together with WOA23 depth levels, landsea_01, basinmask_01, and 1-degree cell areas. Load nitrate to at least one level below 1000 m so the deepest included top-1000 m gradient can use the next deeper level.
2. Load CMIP6 historical no3 for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly 1971-01 to 2000-12, on each native grid; load each model’s depth levels and native areacello/cell areas. Load profiles to at least one level below 1000 m.
3. Use temporal_aggregate to form each model’s day-weighted long-term mean no3 climatology over 1971-2000. WOA23 is already the annual climatology. For the section plots, use transform_unit to put CMIP6 and WOA23 nitrate into one common concentration unit.
4. For WOA23 and each model climatology, use compute_vertical_gradient to compute vertical nitrate gradients layer by layer. Using the loaded depth levels, retain gradients at levels within the top 1000 m, with the 1000 m gradient using the loaded level just below 1000 m. With own code, find for each horizontal cell the depth of the maximum retained gradient and store it as the nitracline depth field. Apply the source’s ocean mask: WOA23 landsea_01 > 1, and non-missing model no3 on native grids.
5. Compute global area-weighted mean nitracline depth for each model on its native grid with its areacello, and for WOA23 on the 1-degree grid with WOA cell areas, using compute_basic_stat. Subtract WOA23 from each model to obtain global differences; report to the nearest metre.
6. Regrid each model nitracline depth to the WOA 1-degree grid with regrid_horizontal. Use load_basin_mask/select_basin to keep Pacific, Atlantic and Indian Ocean cells, with marginal seas folded into their parent basins and Southern and Arctic Oceans excluded. Compute area-weighted basin means with WOA cell areas via compute_basic_stat for WOA23 and each model. Subtract WOA23 in each basin; report to the nearest metre.
7. On the WOA 1-degree grid, use regrid_horizontal for each model nitracline and build_comparison_mask with WOA landsea_01 > 1 and all three regridded fields to define common valid ocean cells. For each model, use analyze_correlation for the spatial Pearson correlation against WOA23 and compute_difference_metrics for RMSE; report correlation to 3 decimal places and RMSE to 1 decimal place.
8. Compare each model’s global and basin differences, spatial correlation and RMSE to identify which model reproduces WOA23 best. Compare each model’s Pacific/Atlantic/Indian nitracline ordering with WOA23’s ordering and report whether it matches.
9. Figure 1: using the fields regridded to the WOA 1-degree grid, make a 2-by-2 global map panel for CESM2, GFDL-ESM4, MPI-ESM1-2-LR and WOA23, all on one shared sequential colour scale with deeper values visually heavier, masking land with WOA23 landsea_01 > 1.
10. Figure 2: load WOA23 and CMIP6 no3 in the equatorial Pacific box 120E to 80W crossing the dateline, 2S-2N, to at least one level below 1000 m; use the 1971-2000 model climatology and WOA annual climatology; transform_unit to one common concentration unit; average over 2S-2N to form longitude-depth sections. Plot WOA23, CESM2, GFDL-ESM4 and MPI-ESM1-2-LR in that order, top 1000 m only with depth increasing downward, one shared colour scale, and overlay each panel’s nitracline line computed by the same top-1000 m maximum-gradient rule on that section.
Other notes:
- Nitracline depth is the depth of maximum vertical nitrate gradient, searched only over levels within the top 1000 m; the gradient at the deepest included level uses the level just below 1000 m.
- Basin averages use the WOA23 basin mask; marginal seas are folded into their parent ocean and Southern and Arctic Oceans are excluded.
- Global means are area-weighted on each model’s native grid and WOA23’s 1-degree grid; basin means are area-weighted on the WOA 1-degree grid after regridding models so the WOA basin mask can be applied.
- Spatial Pearson correlation and RMSE are computed on the WOA23 1-degree grid over common valid ocean cells; correlation is reported to 3 decimal places and RMSE to 1 decimal place.
- Figure 2 uses a common nitrate concentration unit and a shared colour scale; depths increase downward and only the top 1000 m are shown.
- Model skill is assessed from the global/basin differences, spatial correlation and RMSE, and the basin-depth ordering is compared against WOA23.
