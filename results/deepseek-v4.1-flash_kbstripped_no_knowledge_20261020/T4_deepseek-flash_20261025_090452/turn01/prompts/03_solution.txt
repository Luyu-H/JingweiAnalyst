The user's question:
Check whether a mixed layer depth (MLD) computed from each CMIP6 model's own temperature and salinity reproduces the mlotst field that the same model publishes. This is an internal consistency test: both quantities come from the same simulation, so any disagreement is a property of the diagnostic, not of the model's physics.

Data to use:
- CMIP6 historical `thetao`, `so` and `mlotst` from CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly, 1971-01 to 2000-12.
- Each model's own published cell areas (areacello).

Expected numerical results, comparing the 1971-2000 March and September climatologies of the operator MLD with those of the published mlotst, for each of the six model-and-month combinations. The operator MLD is the mixed layer depth computed offline from the model's own thetao and so with the density criterion that defines mlotst, the crossing depth interpolated between the bracketing levels. For each model and calendar month, both climatologies cover only the cells where both fields are defined in all 30 instances of that month (the 30 Marches, or the 30 Septembers):
- The mean difference, operator MLD minus mlotst, in metres to 1 decimal place.
- The root-mean-square difference, in metres to 1 decimal place.
- The spatial Pearson correlation between the two fields, to 3 decimal places.
- The percentage of the area where both fields are defined on which the absolute difference exceeds 20 m, to 1 decimal place, and the area where both fields are defined as a percentage of the model's total ocean area, to 1 decimal place.
- The ranking of the three models from most to least internally consistent, with the criterion used, the regions where the disagreement concentrates, and why the operator and mlotst are not expected to agree exactly.

Expected visualizations:
- Figure 1, a 3-by-2 panel of global maps of operator MLD minus mlotst, rows CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, columns March and September, all six panels drawn as maps on a common longitude-latitude frame (each panel a true geographic map, with curvilinear model fields put on a regular longitude-latitude grid for display only) with one shared diverging colour scale centred on zero.
- Figure 2, a 3-by-2 panel of scatter plots in the same layout, operator MLD on the x axis against mlotst on the y axis, one point per ocean cell, with logarithmic axes of identical range and ticks in every panel, a dashed y = x reference line, and each panel annotated with its bias, root-mean-square difference and correlation.

2. For each model and each month, compute potential density anomaly from thetao and so with compute_potential_density_anomaly.

- The March and September climatologies are restricted to cells where both fields are defined in all 30 Marches or all 30 Septembers; coverage percentages use each model's total ocean area from its own areacello.

import xarray as xr

models = ["CESM2", "GFDL-ESM4", "MPI-ESM1-2-LR"]
months = [3, 9]
MONTH_NAME = {3: "March", 9: "September"}


def _val(x):
    """Materialise a (possibly dask-backed) scalar/0-d object as a float."""
    if hasattr(x, "compute"):
        x = x.compute()
    return float(np.asarray(x))


def _restamp(da, base_attrs, units, long_name):
    """Keep the loader's grid provenance while re-declaring the physical quantity."""
    a = dict(base_attrs)
    a.update(dict(da.attrs))
    a["units"] = units
    a["long_name"] = long_name
    da.attrs = a
    return da


results = {}        # (model, month) -> dict of metric scalars
op_clim = {}        # (model, month) -> operator MLD March/Sept climatology, native grid
ml_clim = {}        # (model, month) -> published mlotst March/Sept climatology, native grid
diff_clim = {}      # (model, month) -> operator - mlotst on the common mask, native grid
diff_map = {}       # (model, month) -> same field regridded to 1 deg for display only
extreme_info = {}   # (model, month) -> locate_extreme output on the difference
coverage = {}       # (model, month) -> coverage percent

for model in models:
    th = load_regular_data(dataset="cmip6_historical", variable="thetao", model=model,
                           time_range=["1971-01", "2000-12"], chunk_time=6)
    sa = load_regular_data(dataset="cmip6_historical", variable="so", model=model,
                           time_range=["1971-01", "2000-12"], chunk_time=6)
    ml = load_regular_data(dataset="cmip6_historical", variable="mlotst", model=model,
                           time_range=["1971-01", "2000-12"], chunk_time=6)
    ar = load_regular_data(dataset="cmip6_historical", variable="areacello", model=model)

    base_attrs = dict(th.attrs)

    # the model's own ocean domain: cells where the published MLD is ever defined
    ocean_cells = ml.notnull().any("time").compute()
    total_ocean_area = float(ar.where(ocean_cells).sum().compute())

    for mm in months:
        th_m = th.sel(time=th.time.dt.month == mm)
        sa_m = sa.sel(time=sa.time.dt.month == mm)
        ml_m = ml.sel(time=ml.time.dt.month == mm)

        # offline MLD with the density criterion that defines mlotst (sigma0 offset 0.03
        # kg m-3 from the 10 m reference level, crossing interpolated between levels)
        mld = compute_mixed_layer_depth(temp_data=th_m, sal_data=sa_m,
                                        ref_depth=10.0,
                                        method="density",
                                        density_threshold=0.03).compute()

        # Common mask built directly on the shared native grid: a cell is kept only if
        # both fields are defined at every one of the 30 instances of this month.
        # (build_comparison_mask is for fields on *different* grids and refuses
        # curvilinear index dimensions, which CESM2 and MPI-ESM1-2-LR use.)
        common = ((mld.notnull()) & (ml_m.notnull())).all("time").compute()

        op_mc = mld.where(common).compute()
        ml_mc = ml_m.where(common).compute()

        oc = _restamp(temporal_aggregate(op_mc, freq="mean").compute(),
                      base_attrs, "m", "operator mixed layer depth")
        mc = _restamp(temporal_aggregate(ml_mc, freq="mean").compute(),
                      base_attrs, "m", "published mlotst")

        d = _restamp((oc - mc).compute(), base_attrs, "m",
                     "operator MLD minus mlotst")

        hdims = list(oc.dims)

        met = compute_difference_metrics(data=oc, reference=mc, dim=hdims,
                                         weighting="area")
        exc = compute_exceedance_fraction(d, threshold=20.0, comparison="abs_greater",
                                          dim=hdims, weighting="area")
        cor = analyze_correlation(var1=oc, var2=mc, dim=hdims, method="pearson")
        loc = locate_extreme(d, op="abs_max")

        cov = float((ar.where(common).sum() / ar.where(ocean_cells).sum()).compute()) * 100.0

        results[(model, mm)] = {
            "bias": _val(met["bias"]),
            "rmse": _val(met["rmse"]),
            "mae": _val(met["mae"]),
            "centered_rmse": _val(met["centered_rmse"]),
            "max_abs_error": _val(met["max_abs_error"]),
            "max_abs_error_at": met["max_abs_error_at"],
            "correlation": _val(cor["correlation"]),
            "pvalue": _val(cor["pvalue"]),
            "frac_gt20": _val(exc["fraction_percent"]),
            "n_common": int(np.asarray(exc["n_valid"])),
            "coverage_percent": cov,
        }
        coverage[(model, mm)] = cov
        extreme_info[(model, mm)] = {
            "value": _val(loc["value"]),
            "coordinates": loc["coordinates"],
            "description": loc["description"],
        }

        op_clim[(model, mm)] = oc
        ml_clim[(model, mm)] = mc
        diff_clim[(model, mm)] = d
        diff_map[(model, mm)] = regrid_horizontal(d, target="woa23",
                                                  method="bilinear").compute()

        print(f"{model:16s} {MONTH_NAME[mm]:10s} "
              f"bias={results[(model, mm)]['bias']:7.1f} m  "
              f"RMSD={results[(model, mm)]['rmse']:6.1f} m  "
              f"r={results[(model, mm)]['correlation']:6.3f}  "
              f"|d|>20m={results[(model, mm)]['frac_gt20']:5.1f}%  "
              f"coverage={cov:5.1f}%  "
              f"max|d|={results[(model, mm)]['max_abs_error']:6.1f} m "
              f"at {extreme_info[(model, mm)]['coordinates']}")

# ---------------------------------------------------------------- ranking
rank_table = []
for model in models:

## Methodology actually used

- Loaded CMIP6 historical monthly `thetao`, `so`, and `mlotst` on Omon, plus fixed `areacello`, for CESM2, GFDL-ESM4, and MPI-ESM1-2-LR over **1971-01 to 2000-12** using `load_regular_data`.
- Selected **March** and **September** separately, giving 30 monthly instances of each month.
- For each model and month, computed the offline operator MLD by calling `compute_mixed_layer_depth` directly on the model’s `thetao` and `so`, with:
  - `ref_depth = 10.0 m`
  - `method = "density"`
  - `density_threshold = 0.03 kg m⁻³`
  - crossing interpolated between bracketing levels by the tool.
- A common mask was built directly on each model’s native grid as the conjunction of non-null operator MLD and non-null published `mlotst` in **all 30 instances** of that month.
- Applied the mask to the monthly series, then used `temporal_aggregate(... freq="mean")` to obtain the 1971–2000 March and September climatologies.
- Computed the difference field as **operator MLD minus published mlotst** from the two climatologies.
- Metrics:
  - bias, RMSD, MAE, centered RMSE, and maximum absolute error via `compute_difference_metrics(... weighting="area")`;

## Interpretation

The high spatial correlations show that the offline diagnostic captures the broad structure of the published mixed layer depth well. The systematic negative bias and localized large differences show that it is not a bitwise reproduction of the online `mlotst` diagnostic. This is expected: `mlotst` is computed online within each model on its native vertical grid and algorithm, whereas the operator MLD is computed offline from archived `thetao` and `so`, with interpolation between levels, a 10 m reference depth, a 0.03 kg m⁻³ density threshold, and possible differences in surface/reference-level treatment, vertical discretisation, density-criterion implementation, and post-processing/archiving.
