def _to_float(x):
    """Plain float from a python/numpy scalar or a (0-d) xr.DataArray.

    compute_difference_metrics returns scalars as floats once every shared
    dimension is reduced, so .values cannot be used blindly.
    """
    if isinstance(x, xr.DataArray):
        x = x.values
    return float(np.asarray(x).reshape(-1)[0])

**Best model.** By the combined rank (|ΔDIC|, |ΔTAlk|, |ΔpH|, map RMSE, vertical RMS bias) GFDL-ESM4 is best (total rank 6), CESM2 second (9), MPI-ESM1-2-LR clearly worst (15).
