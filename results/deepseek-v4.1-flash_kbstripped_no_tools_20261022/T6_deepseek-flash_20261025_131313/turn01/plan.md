# Plan

1. Load the WOA23 nitrate annual all-periods climatology (variable nitrate) on its 1-degree grid, together with landsea_01 (ocean value greater than 1) and basinmask_01. Load CMIP6 historical monthly no3, thetao, so and areacello for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR for 1971-01 to 2000-12, each on its native horizontal grid, native vertical coordinate and own areacello.
   - Note [cmip6-grid-labels]: GFDL-ESM4 no3 is gr, already remapped with conserve_order1 to 180x360, so its native-grid numbers are 1-degree archive numbers on a regridded land-sea mask; CESM2 and MPI-ESM1-2-LR differ by about 2.5x in resolution, so sharp-gradient features of the nitracline are not comparable in amplitude.

2. Average each model's monthly no3 over 1971-2000 with a month-length-weighted time mean, using temporal_aggregate(freq='mean'); the WOA23 nitrate field is already the all-period annual climatology. Keep the model no3 in its archived mol m-3 basis for locating the gradient, and convert a copy to µmol kg-1 for comparisons and sections using in-situ density from compute_potential_density_anomaly(ref_pressure=None) built from model thetao and so; record attrs['density_assumption'] and state the density assumption.
   - Note [monthly-means-are-time-averages]: average first, then locate the nitracline, which is the diagnostic of the mean state and the like-for-like choice against the WOA23 climatology; temporal_aggregate weights by month length and compute_basic_stat(op='mean', dim='time') is not a time average.
   - Note [cmip6-bgc-units-per-volume]: no3 is archived in mol m-3 while WOA23 is µmol kg-1, so convert to one basis before differencing or shared-unit plotting, using in-situ density from compute_potential_density_anomaly(ref_pressure=None), not transform_unit's constant default; state attrs['density_assumption']. The gradient-depth location is scale-invariant for a constant density, but in-situ density grows with depth and shifts it slightly, so locate the nitracline on the native field and state which basis was used.

3. Compute the nitracline depth for WOA23 and each model on each source's native vertical grid: for every profile, calculate finite-difference vertical gradients between adjacent native levels for pairs whose upper level is at or above 1000 m, using the next deeper level for the deepest allowed pair; load and use levels below 1000 m only to close that deepest gradient; set the nitracline depth to the depth of the level with the maximum gradient. Apply each product's valid ocean mask; do not vertically interpolate to locate the nitracline. Locate the models on their native archived mol m-3 field and WOA23 on its native µmol kg-1 field.

4. Compute native-grid global and basin mean nitracline depths: use WOA23 regular-grid cell areas for WOA23 and each model's own areacello for the models, masking the weights to the same valid cells. For basins, use the WOA23 basin mask with include_marginal_seas=True and depth_dependent=False surface labels, select Pacific, Atlantic and Indian, and exclude the separate Southern and Arctic basins; map the surface labels to each native model grid for basin assignment only. Save these native-grid means for reporting.
   - Note [omip-weighted-means-and-integrals]: global and basin means must be area-weighted with weights masked to the same valid cells; compute_difference_metrics weights by area by default, and analyze_correlation needs weighting='area'.
   - Note [basin-and-region-definitions]: basin means use the WOA23 basin mask with include_marginal_seas=True, marginal seas folded into their parent ocean, and depth_dependent=False surface labels applied through the column; state that the Ofx basin field is not in the local archive, and report whether the Southern Ocean is separate or split among the three oceans, which here is separate and excluded along with the Arctic.
   - Note [omip-native-grid-vs-regridded]: compute global and basin mean nitracline depths on each source's own grid with its own cell areas; regrid to the WOA 1-degree grid only for maps, the pattern correlation and the RMSE, and state the regrid method and direction (conservative remapping to the 1-degree target). The nitracline is located at a vertical extremum and is quantised by each product's vertical grid, so read the maps together with the gradient itself.

5. Regrid the three model nitracline-depth fields to the WOA23 1-degree grid using conservative remapping, stating the method and whether the target is coarser or finer for each source; GFDL-ESM4 is already a 1-degree archive for no3. Build one comparison mask with build_comparison_mask(ocean_only=True) from the WOA23 land-sea mask and valid overlap, apply .where(mask) to all four nitracline fields, and report the mask's cell count with the metrics. On that shared sample, compute each model's area-weighted Pearson pattern correlation with WOA23 (analyze_correlation weighting='area'), RMSE in metres, and mean_data/mean_reference/difference from compute_difference_metrics; take each model-WOA23 difference from those shared-sample means, not as a difference of means computed on different cells. Compute shared-sample basin means for basin differences in the same way.
   - Note [common-comparison-mask]: regrid all four nitracline fields to the 1-degree WOA23 grid, build one mask with build_comparison_mask and apply .where(mask) to every field before the correlation, RMSE and differences; ocean_only=True is correct because WOA23 is part of the comparison. Report the mask's cell count with the metrics and take each model's difference from WOA23 on that one shared sample using compute_difference_metrics' mean_data/mean_reference, not as a difference of means on different cells.

6. Figure 1: make a 2-by-2 panel of global maps of nitracline depth for WOA23, CESM2, GFDL-ESM4 and MPI-ESM1-2-LR on the common-masked WOA23 1-degree grid, using one shared sequential colour scale on which deeper values are visually darker and heavier, with land masked.

Report the requested results: native area-weighted global means to the nearest metre and each model's shared-sample difference from WOA23; Pacific, Atlantic and Indian basin means to the nearest metre and each model's basin differences; area-weighted pattern correlation to 3 decimals and RMSE to 1 decimal. Identify the model that reproduces the observed nitracline best using the highest correlation and lowest RMSE, supported by global and basin biases, and state whether each model reproduces WOA23's ordering of nitracline depth across the Pacific, Atlantic and Indian basins.

Other notes:
- WOA23 nitrate is the single all-period composite, not a 1971-2000 normal, while the model climatology is 1971-2000, so a period mismatch is inherent in the comparison.
- Figure 2's common longitude and depth axes are for display only; all nitracline depths and metrics are located or computed on the native vertical grids before any display interpolation.
- The deepest searched gradient is the one whose upper level is at or above 1000 m and whose lower level is just below 1000 m; no gradient with an upper level below 1000 m is included.
- The basin-order assessment is a rank comparison of each source's Pacific, Atlantic and Indian basin means, not a magnitude comparison alone.
