# Plan

1. Open the WOA23 raw files for oxygen, percent_oxygen_saturation, apparent_oxygen_utilization, landsea_01 and basinmask_01. Use the WOA23 oxygen product and its 1971-2000 normal where that normal exists; where the dataset exposes only the all-period oxygen composite, use that field and record the difference in Other notes. Decode 1e20 as NaN, apply landsea_01 as the WOA ocean mask, average the monthly climatology to an annual climatology with day weights, and build WOA cell geometry from the 1° spherical cell area and layer thickness from the depth-coordinate bounds on the WOA native levels.
- Note [monthly-means-are-time-averages]: average the monthly fields to the period with day weights before forming oxygen thresholds; WOA is a climatology, so use average-then-diagnose, not diagnose-monthly-then-average.

2. Open CMIP6 historical o2, thetao and so for GFDL-ESM4 and MPI-ESM1-2-LR, monthly 1971-01 to 2000-12, and ssp245 o2, thetao and so for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly 2071-01 to 2100-12. Open each model's own volcello, areacello and deptho. Decode 1e20 as NaN, and build each field's valid ocean mask from the field itself.
- Note [missing-values-and-land-cells]: read 1e20 as NaN; masks differ between variables of the same model, so build each field's valid mask from the field itself and mask volcello/areacello to the same cells; keep missing cells out of both numerator and denominator in any below-threshold fraction.

3. For each model and period, use the model calendar and day weights to form period-mean thetao, so and o2. Keep the native o2 in mol m-3 for inventory calculations, and derive all threshold diagnostics from the period-mean converted fields. [monthly-means-are-time-averages]

4. Convert model o2 from mol m-3 to micromoles per kilogram using in-situ density computed from the period-mean thetao and so on the model's native levels, with potential density anomaly evaluated at the in-situ pressure (`ref_pressure=None`). Use converted o2 = o2_native × 1e6 / rho. Record and state the density_assumption used. Do not use a constant surface-density default for this conversion. Keep the native mol m-3 o2 separately for the inventory.
- Note [cmip6-bgc-units-per-volume]: convert with in-situ density before applying the 20 and 60 micromoles per kilogram thresholds and state the density_assumption; for inventories integrate the native mol m-3 field as Σ c·volcello with no density factor.

5. For WOA23 and each available model-period (WOA23; GFDL-ESM4 and MPI-ESM1-2-LR historical; CESM2, GFDL-ESM4 and MPI-ESM1-2-LR ssp245), compute the total OMZ volume at strictly below 20 and strictly below 60 micromoles per kilogram by summing cell volume (WOA cell volume or model volcello) over valid cells satisfying the threshold. Report in 1e15 m3 to 3 significant figures, keeping unrounded values for later changes.
- Note [omip-weighted-means-and-integrals]: OMZ volume is Σ volcello over valid below-threshold cells, a share of volume rather than a count of cells; volume-weight every mean and integral.
- Note [cmip6-o2sat-and-derived-oxygen]: evaluate oxygen thresholds in the field's own units, so use the converted model o2 field before flagging OMZ cells; WOA percent saturation and AOU rest on the WOA convention and pressure assumptions, so model-WOA AOU or percent-saturation differences include a definitional component.

6. Compute the maximum OMZ thickness at the 60 threshold for each source-period: in each column, sum the thickness of levels whose period-mean o2 is strictly below 60. For CMIP6 use cell thickness = volcello / areacello on the native levels; for WOA use depth-coordinate layer thickness on its native levels. Find the maximum thickness and its latitude/longitude, reporting metres to 1 decimal place and latitude/longitude to 2 decimal places.
- Note [cmip6-static-grid-fields]: there is no thkcello or masscello; use volcello/areacello for column thickness, not lev_bnds differences, which fail at partial bottom cells; use deptho or the field's own fill pattern for sea-floor decisions.
- Note [omip-native-grid-vs-regridded]: compute thickness on each source's native levels and do not vertically interpolate for OMZ thickness; regrid only the map fields later, and build one shared mask before cell-by-cell map comparisons.

7. Compute basin-resolved OMZ volumes at the 60 threshold for WOA23, GFDL-ESM4 historical and MPI-ESM1-2-LR historical. Apply the WOA23 basinmask_01: retain Pacific, Indian and Atlantic, fold marginal seas into their parent ocean, and exclude the Southern and Arctic Oceans. On WOA use its native cell volumes. For each model, map the categorical WOA basin mask to the model's own native grid by nearest neighbour without smoothing, then sum model volcello over valid below-60 cells in each basin. Report in 1e15 m3 to 3 significant figures. [omip-weighted-means-and-integrals; omip-native-grid-vs-regridded]

8. For WOA23, define the OMZ by oxygen strictly below 60 micromoles per kilogram, then compute the volume-weighted mean apparent_oxygen_utilization and percent_oxygen_saturation within those cells using WOA cell volumes and each variable's valid mask. Report AOU in micromoles per kilogram and percent saturation to 1 decimal place, and use the pair to interpret whether the zone is consistent with respiration-driven oxygen loss or poor ventilation. [cmip6-o2sat-and-derived-oxygen]

9. Compute the global dissolved oxygen inventory for GFDL-ESM4 and MPI-ESM1-2-LR historical and for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR ssp245 by summing native o2 [mol m-3] × volcello [m3] over valid ocean cells on each native grid, using the period-mean fields. Report moles to 3 significant figures. [cmip6-bgc-units-per-volume]

10. For GFDL-ESM4 and MPI-ESM1-2-LR, compute the historical-to-ssp245 percentage change in OMZ volume at both the 20 and 60 thresholds as 100 × (V_ssp245 − V_historical) / V_historical using unrounded volumes; positive means an expanding OMZ. Report to 2 decimal places. CESM2 cannot enter this calculation because it has no historical o2.

11. Compare the WOA23, GFDL-ESM4 historical and MPI-ESM1-2-LR historical OMZ volumes at both thresholds, and the 60-threshold basin volumes, to identify which model reproduces the observed total OMZ volume better. Compare the two available models' scenario changes in sign and size using the unrounded changes.

12. Build Figure 1: three global maps in one row of historical OMZ thickness at the 60 threshold for GFDL-ESM4, MPI-ESM1-2-LR and WOA23. Compute thickness on each native grid, then regrid the model thickness fields to the WOA 1° grid only for plotting; use WOA landsea_01 for land masking and one shared sequential colour scale in metres.

13. Build Figure 2: three global maps in one row. For GFDL-ESM4 and MPI-ESM1-2-LR, compute the change in 60-threshold OMZ thickness as ssp245 2071-2100 minus historical 1971-2000 on the native grid, then regrid the difference to the WOA 1° grid for plotting; use one shared diverging colour scale centred on zero for these two panels. For CESM2, plot its ssp245 60-threshold OMZ thickness on its own sequential colour scale, labelled to show that no historical o2 is available and therefore no change can be formed. [omip-native-grid-vs-regridded]

Other notes:
- WOA23 oxygen, percent oxygen saturation and AOU are published as a single all-period composite in this dataset, not as a separate 1971-2000 oxygen normal; the WOA oxygen climatology used here is therefore the all-period oxygen composite, even though the question requested the 1971-2000 normal.
- CESM2 has no historical o2, so no CESM2 historical OMZ volume, historical OMZ thickness, historical inventory, basin comparison or historical-to-ssp245 change is possible; only its ssp245 fields are used.
- Model threshold volumes and thicknesses are average-then-diagnose from period-mean fields; the density assumption used for the model oxygen conversion is the one computed in step 4.
- The WOA23 basin mask is categorical and is mapped to each model grid by nearest neighbour; this defines the model basin boundaries as closely as the WOA mask allows, while WOA-native basin volumes use the mask directly.
