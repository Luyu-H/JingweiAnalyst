For woa23, read the all-time-period annual `nitrate` objectively analysed climatology, `landsea_01` and `basinmask_01` on the 1-degree grid. Decode missing/1e20 values to NaN, build each field's valid-ocean mask from the field itself, and for WOA require `landsea_01 > 1`. Determine native level depths and retain the levels within the top 1000 m plus the first level below 1000 m needed for the deepest gradient.
- Note [missing-values-and-land-cells]: decode 1e20 to NaN via xarray, keep every reduction NaN-aware with weights masked to the same cells so land stays missing rather than contributing 0, build each field's mask from that field, and treat any near-1e20 output as an unmasked fill.

2. Form each model's 1971-2000 annual-mean `no3` climatology by day-weighting the 240 monthly fields and averaging over time; do not use an equal-weight `mean(dim='time')`. WOA23 is already an annual all-period climatology. Perform this temporal averaging before locating any vertical gradient.
- Note [monthly-means-are-time-averages]: use a day-weighted monthly mean for 1971-2000; average first and then locate the gradient, which is the like-for-like choice for a climatology reference, and state that sub-monthly variance cannot be recovered.

3. On each source's native grid, compute the nitracline from its annual nitrate field. For every upper level with depth `z_i <= 1000 m`, compute the forward vertical gradient `(NO3_{i+1} - NO3_i)/(z_{i+1} - z_i)` using the next level below, including the deepest level at or above 1000 m with the first level below 1000 m. Take the depth `z_i` of the maximum positive gradient as the nitracline depth; leave NaN where no valid level pair exists. Do this separately for WOA23 and each model.
- Note [cmip6-bgc-units-per-volume]: locate the nitracline from the native `no3` field with no density conversion; for Figure 2's single concentration unit, convert with in-situ density (`compute_potential_density_anomaly` with `ref_pressure=None`) and record `attrs['density_assumption']`.

4. Compute global and Pacific/Atlantic/Indian area-weighted mean nitracline depths on each source's native grid: `Σ nitracline·weight / Σ weight` over valid cells, using each model's own `areacello` and spherical cell areas computed from the WOA grid for WOA. Decode the WOA23 `basinmask_01` using surface labels (`depth_dependent=False`), with marginal seas folded into their parent ocean and the Southern and Arctic Oceans excluded. Use the same WOA-derived basin labels for models by sampling the categorical mask onto each native model grid without regridding any nitracline field for these means; use the WOA mask/labels and WOA cell areas for WOA. Compute each model-minus-WOA difference in the global mean and in each basin.
- Note [basin-and-region-definitions]: basin statistics use the WOA23 basin mask (not the OMIP 10-region mask), marginal seas are included in parent oceans, Southern and Arctic are separate basins and excluded here, a 2-D field uses surface labels (`depth_dependent=False`), and the same basin mask must underlie model and observational basin means.
- Note [omip-weighted-means-and-integrals]: every mean is area-weighted over valid cells (`Σ nitracline·areacello / Σ areacello`) with the basin mask applied on the same grid; unweighted means over `(y,x)` or over latitudes on a regular grid are wrong, and the difference metrics/correlation must also be weighted.
- Note [omip-native-grid-vs-regridded]: compute each model's global and basin mean nitracline on its native grid with its own `areacello`; regrid to the WOA 1-degree grid only for the maps, pattern correlation and RMSE, using conservative regridding to the coarser grid and bilinear only as a fallback; state the method actually used, and remember the nitracline is a vertical-extremum diagnostic quantised by the native vertical grid.

5. Regrid the three model nitracline fields from their native grids to the WOA 1-degree grid for maps and metrics, as required by [omip-native-grid-vs-regridded]. Build one shared valid comparison mask over the four regridded nitracline fields, with WOA23 subject to its default ocean-only treatment, apply it with `.where(mask)` before the pattern correlation and RMSE, and record the mask cell count.
- Note [common-comparison-mask]: build one shared valid mask over the four nitracline fields and apply it before the pattern correlation and RMSE; report its cell count beside the metrics, and state that global/basin differences from WOA23 are differences of area-weighted means each taken on its own grid, not the bias over the shared mask.

Report correlations to 3 decimal places and RMSE to 1 decimal place.
