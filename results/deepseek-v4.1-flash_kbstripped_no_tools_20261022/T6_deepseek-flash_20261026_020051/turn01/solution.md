In other words, at some point the code performed two-dimensional indexing (`arr[i, j]` or `arr[:, k]`) on an array that only had one dimension. The most likely origin, judging from the code as written, is the WOA23 **ASCII mask ingestion**, which the code implemented itself rather than using xarray. `read_msk_rows()` was written to parse the WOA `.msk` files as whitespace-separated numeric rows, keeping only lines with at least two numeric fields, and then `landsea_arr = np.array(landsea_rows)` was immediately indexed as `landsea_arr[:, 0]` and `landsea_arr[:, 1]`.
