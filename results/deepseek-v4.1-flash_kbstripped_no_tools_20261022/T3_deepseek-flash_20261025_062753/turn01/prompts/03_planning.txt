[cmip6-grid-labels] (should)

- Resolution differs about 2.5× between CESM2 and MPI-ESM1-2-LR, so features narrower than the coarse grid are not comparable in amplitude.

[cmip6-tos-bulk-top-cell] (should)
- `tos` is the bulk temperature of the top model cell, including under sea ice, so a global mean carries near-freezing polar values; top cells differ (CESM2 0–10 m, GFDL-ESM4 0–2 m, MPI-ESM1-2-LR 0–12 m), so "SST" is not the same layer across the models.

[missing-values-and-land-cells] (should)
- CMIP6 files mark land and below-sea-floor cells with the missing value 1e20; any read path that skips CF masking (raw netCDF4 arrays, scale/offset before masking, float32 overflow) turns those into huge numbers that silently dominate sums and means.

[cmip6-static-grid-fields] (should)
- Weight each mean by the model's own `areacello` (tracer-cell area, zero or missing over land); on a curvilinear grid it is the only correct area weight.
- Total ocean area differs between models by about a per cent because each resolves the coastline differently — state the area each mean was taken over rather than rescaling one model to another.
