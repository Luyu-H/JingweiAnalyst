# Plan

1. Open `cmip6_historical` and `glodap`. From `cmip6_historical`, read CESM2, GFDL-ESM4 and MPI-ESM1-2-LR monthly `dissic`, `talk`, `ph`, `thetao` and `so` for calendar year 2002, and `dissic`, `thetao` and `so` for 1971-2000, plus each model's `areacello` and `volcello`. From `glodap`, read `TCO2`, `TAlk` and `pHtsinsitutp`. Mask CMIP6 missing values and land/below-sea-floor cells before any arithmetic; keep each product on its native grid and depth coordinate. Use `pHtsinsitutp` as the GLODAP total-scale in-situ pH field.
- Note [missing-values-and-land-cells]: mask the CMIP6 missing value 1e20 and land/below-sea-floor cells before sums/means so they cannot dominate.
- Note [cmip6-carbonate-system-definitions]: `dissic` is total DIC, `talk` is total alkalinity including carbonate/borate/water/phosphate/silicate/nitrogen terms, and `ph` is in-situ pH on the TOTAL scale; all three models use OMIP best-practice constants.

2. For each model and each month, compute in-situ density from `thetao` and `so` with `compute_potential_density_anomaly(ref_pressure=None)`, then convert monthly `dissic` and `talk` to µmol kg-1 with `transform_unit` using µmol kg-1 = mmol m-3 × 1000 / ρ. Form the 2002 annual means of converted `dissic`, `talk` and `ph`, and the 1971-2000 mean of converted `dissic`. For each source compute one volume-weighted 0-50 m global mean over all its cells whose depth coordinate is 0-50 m: CMIP6 using its own `volcello` (for GFDL-ESM4, average its monthly `volcello` onto the annual-mean grid and align period weights to the same months); GLODAP using its 1-degree cell area times its standard-level thickness because GLODAP supplies no `volcello`. Compute DIC, TAlk and pH means for each model and GLODAP, and each model-minus-GLODAP difference.
- Note [cmip6-bgc-units-per-volume]: use the in-situ density from `ref_pressure=None` in the conversion; do not use the constant-density default, and state the resulting `density_assumption`; never relabel mol m-3 × 1e3 as µmol kg-1.
- Note [omip-weighted-means-and-integrals]: compute the 0-50 m global means with `volume_weighted_mean` using `volcello` NaN-masked to the same cells; do not use a plain mean over (y, x).
- Note [omip-native-grid-vs-regridded]: compute every global number on each source's own grid with its own weights; regrid horizontally only for map comparison, with method `'conservative'`; use `regrid_vertical` for the 0, 100, 500, 1000 and 2000 m values rather than selecting the nearest level; the vertical-profile comparison is the question-required exception because it must be made on the GLODAP grid.

3. For each model and for GLODAP, compute the 0-50 m DIC map as each horizontal cell's mean over its own depth levels within 0-50 m. Regrid each model map conservatively to the GLODAP 1-degree grid. Build one comparison mask with `build_comparison_mask` on the GLODAP grid using `ocean_only=False`, apply `.where(mask)` to GLODAP and all model maps, and report the mask cell count. Form each model-minus-GLODAP bias map and compute mean bias and RMSE with `compute_difference_metrics` (area-weighted by default) and spatial correlation with `analyze_correlation(weighting='area')`.
- Note [common-comparison-mask]: put all fields on the GLODAP 1-degree grid, build one mask and apply it before any bias/RMSE/correlation; pass `ocean_only=False` because the reference is GLODAP; report the mask cell counts; take means from `compute_difference_metrics` over the shared sample; for the depth profile use the cells shared at each depth, since a surface mask does not carry to another level.

4. For each model, take the 2002 annual-mean DIC in µmol kg-1 and GLODAP `TCO2`; interpolate each product vertically with `regrid_vertical` to 0, 100, 500, 1000 and 2000 m. Regrid each model depth field conservatively to the GLODAP 1-degree grid. At each depth, form the per-depth shared finite mask where that model and GLODAP are both defined, compute the area-weighted global mean DIC bias (model minus GLODAP) over those cells using GLODAP 1-degree cell area, and retain the five profile values for Figure 2. [common-comparison-mask] applies per depth here.

5. For each model compute the 2002 annual-mean 0-50 m global DIC minus the 1971-2000 mean 0-50 m global DIC, on its own grid with its own `volcello`. Divide this period change by that model's 0-50 m DIC difference from GLODAP obtained in step 2. Report the change in µmol kg-1 and the ratio to 2 decimal places, with the interpretation caveat.
- Note [anomaly-baselines-and-climate-indices]: the 2002-minus-1971-2000 DIC change is internal to each model; against a field's own climatology its GLODAP bias cancels, so the change is small relative to the GLODAP bias and the ratio does not turn that bias into a model error.

6. Make Figure 1 from the step 3 bias maps: three global maps in one row, one per model, on the map-comparison cells, with one diverging colour scale centred on zero shared by all panels and labelled in µmol kg-1. Make Figure 2 from the step 4 profile: depth on the vertical axis increasing downward, DIC bias on the horizontal axis, one line per model, a vertical zero line, and the five sampled depths marked. Tabulate the requested values using unrounded intermediates and round only the reported values to the requested precision. Determine the best model from the combined absolute DIC/TAlk/pH biases, DIC map RMSE and correlation, and profile bias, and state whether the DIC, TAlk and pH errors are consistent in sign across models and across variables within each model.
Other notes:
- [cmip6-grid-labels] GFDL-ESM4 is on `grid_label='gr'` (1-degree archive grid with a regridded land-sea mask and only approximately conservative budgets); its `volcello` is monthly because 75 hybrid levels were remapped to 35 z levels. CESM2 (~100 km) and MPI-ESM1-2-LR (~250 km) differ by about 2.5× in resolution, so narrow features are not comparable in amplitude; weigh this when naming the best model.
- GLODAP provides no `volcello`; its 0-50 m volume weights are constructed from its 1-degree cell area and standard-level thickness, while CMIP6 means use each model's own `volcello`.
- All model differences are model minus GLODAP; pH means and differences are dimensionless total-scale pH units, while DIC and TAlk are in µmol kg-1.
