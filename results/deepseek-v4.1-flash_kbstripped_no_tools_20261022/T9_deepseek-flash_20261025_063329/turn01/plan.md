# Plan

1. Open the raw files with xarray: `ersst` monthly `sst` for 1950-01 to 2014-12; `cmip6_historical` monthly `tos` for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, plus each model’s `areacello` fixed field; and the `pdo` product from `cpc_indices`. Convert longitudes consistently to 0–360, sort longitude, inspect time/lat/lon, align all series to the common 1950-01–2014-12 months, and record the published PDO `base_period` attribute.
   - Note [cmip6-tos-bulk-top-cell]: `tos` is the bulk temperature of the top model cell; values near −1.8 °C under sea ice are valid data, not missing, so make ocean masks consistent before comparing.

2. For each source, compute its own monthly climatology on its native grid over 1950-2014 (one value per calendar month), subtract it to form anomalies, compute the per-month global-mean SST anomaly by area-weighting over available global ocean (using each model’s `areacello`; using cos-latitude cell areas for ERSSTv5), and subtract that scalar from every cell. Then bilinearly regrid the global-mean-removed anomaly fields to the common 1° North Pacific grid over 20N–70N, 110E–260E. Each model index is formed from its own climatology, never from an observed climatology.
   - Note [monthly-means-are-time-averages]: the 1950-2014 monthly climatology is the plain mean of each calendar month across years; day weights do not enter.
   - Note [anomaly-baselines-and-climate-indices]: remove each source’s own climatology; record the published `pdo` `base_period`; the source indices follow the question’s 1950-2014 baseline and any baseline difference is stated.
   - Note [cmip6-grid-labels]: GFDL-ESM4 `tos` is `gr`, already remapped (conserve_order1) to 1° with the regridded land–sea mask; CESM2 and MPI-ESM1-2-LR are `gn` and must be regridded; CESM2 (100 km) and MPI (250 km) differ by about 2.5× in resolution, so features narrower than the coarse grid are not comparable in amplitude.
   - Note [omip-native-grid-vs-regridded]: put every source, observations included, on one common grid before the EOF and take its numbers there; quote bilinear interpolation, since the pattern correlation depends on it; build a shared valid-data mask after regridding before pattern statistics.

3. On the common 1° North Pacific grid, build one shared valid-data mask: retain a cell only if all four regridded anomaly fields are finite for every month over 1950-2014. Apply this same mask to ERSSTv5, CESM2, GFDL-ESM4 and MPI-ESM1-2-LR before the EOF and all pattern/amplitude statistics.
   - Note [common-comparison-mask]: use one mask over all four fields and apply it to every field; cell-by-cell pattern and amplitude comparisons use only cells all sources cover; WOA23’s land-sea mask is not used because WOA23 is not part of this comparison.

4. For each source separately, take the masked anomaly matrix, weight each cell by sqrt(cos latitude), and compute the leading EOF by SVD. Report the percentage of variance explained as 100 × λ1 / sum(λ), to 1 decimal place. Standardize the leading principal-component time series over 1950-2014 (mean 0, SD 1), fix its sign so that positive index = negative SST anomalies in the central and western North Pacific, and compute the regression pattern by regressing the masked anomalies at each cell on the standardized index, giving °C per standard deviation. Compute the amplitude as the area-weighted RMS of the regression pattern over the common domain using cos-latitude cell areas, to 3 decimal places.
   - Note [eof-modes-and-pdo-index]: remove each cell’s annual cycle and the global-mean SST anomaly, weight by sqrt(cos latitude) before the EOF; fix the EOF sign by the stated convention; compare explained variance only on the same common grid and period; amplitude is the area-weighted RMS of the regression pattern (anomalies regressed on the standardized index, °C per SD), not of the EOF; the question’s plain spatial Pearson is followed and its difference from area-weighted `analyze_correlation(weighting='area')` is stated.

5. For each of the four standardized indices, compute the lag-1-year (12-month) autocorrelation as the Pearson correlation between index(t) and index(t−12) over all overlapping months, and report it to 3 decimal places.

6. Align the ERSSTv5-derived standardized index with the published monthly `pdo` series over 1950-2014 and compute their Pearson correlation as-is, with no detrending, reporting it to 3 decimal places. Record what the correlation does and does not demonstrate.
   - Note [serial-correlation-and-significance]: compare the rebuilt ERSSTv5 index with the published `pdo` as-is, no `detrend=True`, because their shared trend is part of the agreement being checked; with a small effective sample size the correlation is unstable; a spatial pattern correlation has no effective-sample correction, so read the coefficient, not its p-value.

7. For each model, compute the plain unweighted spatial Pearson correlation between its regression pattern and the ERSSTv5 regression pattern over the shared valid cells of the common domain, and report it to 3 decimal places. Use these correlations to identify the model that reproduces the observed pattern best; read the coefficients, not p-values [serial-correlation-and-significance].

8. Compute the 9-year (108-month) centred running mean of the ERSSTv5 standardized index where the full 108-month window exists. Detect sign changes in that smoothed series, assign each to the year of the first month with the new sign, and merge any crossing less than 3 years after the last counted transition into that earlier transition, keeping the earlier year. List the resulting observed PDO phase-transition years and compare them with documented Pacific climate shifts (for example the 1976/77 regime shift and other published shift years), reporting which transitions correspond.

9. Summarize: compare each model’s amplitude and lag-1-year autocorrelation with the ERSSTv5 values and state whether they are consistent with observations. State that the ERSSTv5-derived-index correlation with the published PDO demonstrates temporal agreement of the reconstructed leading-mode index with the published PDO series over 1950-2014, but does not demonstrate an identical spatial pattern, a mechanistic causal link, or independent model validation.

10. Produce Figure 1 as a 2-by-2 panel of the regression patterns in the order ERSSTv5, CESM2, GFDL-ESM4, MPI-ESM1-2-LR, using one diverging colour scale centred on zero and labelled in °C per standard deviation; annotate each panel with its explained variance and, for the models, its pattern correlation with ERSSTv5. Produce Figure 2 as a single time-series panel of the standardized indices of all four sources plus the published PDO as a distinguishable fifth line (standardized over the same window for plotting), with the 9-year smoothed ERSSTv5 curve and the transition years marked, and the y-axis labelled as a standardized index.

Other notes:
- All fields are placed on the common 1° grid by bilinear interpolation; GFDL-ESM4 is already `gr`, while CESM2 and MPI-ESM1-2-LR are regridded from `gn`.
- The 108-month centred running mean is defined only where a full 108-month window exists, so the transition years are found on those valid centres even though the record spans 1950-2014.
- The published PDO series is dimensionless and has its own base period; the ERSSTv5-derived index follows the question’s 1950-2014 baseline, and any baseline offset is recorded/standardized away for plotting.
- Spatial pattern correlations are plain unweighted Pearson correlations as requested, not area-weighted correlations.
- EOF signs are arbitrary except for the stated convention that positive index corresponds to negative SST anomalies in the central and western North Pacific.
