The user's question:
Check whether a mixed layer depth (MLD) computed from each CMIP6 model's own temperature and salinity reproduces the mlotst field that the same model publishes. This is an internal consistency test: both quantities come from the same simulation, so any disagreement is a property of the diagnostic, not of the model's physics.

Data to use:
- CMIP6 historical `thetao`, `so` and `mlotst` from CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly, 1971-01 to 2000-12.
- Each model's own published cell areas (areacello).

Expected numerical results, comparing the 1971-2000 March and September climatologies of the operator MLD with those of the published mlotst, for each of the six model-and-month combinations. The operator MLD is the mixed layer depth computed offline from the model's own thetao and so with the density criterion that defines mlotst, the crossing depth interpolated between the bracketing levels. For each model and calendar month, both climatologies cover only the cells where both fields are defined in all 30 instances of that month (the 30 Marches, or the 30 Septembers):
- The mean difference, operator MLD minus mlotst, in metres to 1 decimal place.
- The root-mean-square difference, in metres to 1 decimal place.
- The spatial Pearson correlation between the two fields, to 3 decimal places.
- The percentage of the area where both fields are defined on which the absolute difference exceeds 20 m, to 1 decimal place, and the area where both fields are defined as a percentage of the model's total ocean area, to 1 decimal place.
- The ranking of the three models from most to least internally consistent, with the criterion used, the regions where the disagreement concentrates, and why the operator and mlotst are not expected to agree exactly.

- Figure 1, a 3-by-2 panel of global maps of operator MLD minus mlotst, rows CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, columns March and September, all six panels drawn as maps on a common longitude-latitude frame (each panel a true geographic map, with curvilinear model fields put on a regular longitude-latitude grid for display only) with one shared diverging colour scale centred on zero.

def files_for(model, var):
    """Return files for one model/variable, using the variant parsed from filenames."""
    d = os.path.join(root, model, var)
    files = sorted(glob.glob(os.path.join(d, f"{var}_*.nc")))
    if not files:
        raise FileNotFoundError(f"No files found for {model} {var} under {d}")

    variants = []
    for f in files:
        parts = os.path.basename(f).split("_")
        if len(parts) < 5:
            raise ValueError(f"Cannot parse variant from filename: {f}")
        variants.append(parts[4])

    # Do not assume r1i1p1f1.  Pick the variant actually present.
    variant = Counter(variants).most_common(1)[0][0]
    files = [f for f, v in zip(files, variants) if v == variant]
    return files, variant


def open_omon(model, var):
    files, variant = files_for(model, var)
    ds = xr.open_mfdataset(
        files,
        combine="by_coords",
        use_cftime=True,
        decode_times=True,
        chunks={"time": 1},
    )
    return ds, variant


def select_1971_2000(ds):
    t = ds.time
    sel = (t.dt.year >= 1971) & (t.dt.year <= 2000)
    idx = np.where(sel.values)[0]
    return ds.isel(time=idx)


def open_ofx(model, var):
    files, variant = files_for(model, var)
    if len(files) == 1:
        ds = xr.open_dataset(files[0], use_cftime=True, decode_times=True)
    else:
        ds = xr.open_mfdataset(
            files, combine="by_coords", use_cftime=True, decode_times=True
        )
    return ds, variant


def get_lat_lon_2d(ds, meta):
    lat_da, lon_da = xr.broadcast(
        ds[meta["lat_coord"]], ds[meta["lon_coord"]]
    )
    lat2d = lat_da.transpose(meta["y_dim"], meta["x_dim"]).values.astype("float64")
    lon2d = lon_da.transpose(meta["y_dim"], meta["x_dim"]).values.astype("float64")
    return lat2d, lon2d


def compute_operator_mld(thetao, so, depth_m, lat2d, lon2d):
    """
    Density-criterion MLD from one monthly thetao/so profile.

    thetao, so : (nlev, ny, nx), thetao is potential temperature and so is
                 practical salinity.  Density is potential density referenced
                 to the shallowest level in each column.  The crossing of
                 rho = rho(ref) + 0.03 kg m-3 is linearly interpolated.
    """
    nlev, ny, nx = thetao.shape

    # GSW expects longitude in a conventional range.
    lon_gsw = ((lon2d + 180.0) % 360.0) - 180.0

    z = -np.broadcast_to(depth_m[:, None, None], (nlev, ny, nx))
    lat3 = np.broadcast_to(lat2d[None, :, :], (nlev, ny, nx))
    lon3 = np.broadcast_to(lon_gsw[None, :, :], (nlev, ny, nx))

    p = gsw.p_from_z(z, lat3)

    # so is practical salinity (units "0.001", values ~35).
    SA = gsw.SA_from_SP(so, p, lon3, lat3)
    CT = gsw.CT_from_pt(SA, thetao)

    # Potential density referenced to the shallowest level in each column.
    p_ref = p[0, :, :]
    p_ref3 = np.broadcast_to(p_ref[None, :, :], (nlev, ny, nx))
    rho = gsw.rho(SA, CT, p_ref3)

    ref_rho = rho[0, :, :]
    threshold = ref_rho + 0.03

    cond = rho > threshold[None, :, :]
    has_crossing = np.any(cond, axis=0)
    idx = np.argmax(cond, axis=0)

    idx_exp = idx[None, :, :]
    rho_idx = np.take_along_axis(rho, idx_exp, axis=0)[0]

    i_prev = np.maximum(idx - 1, 0)
    rho_prev = np.take_along_axis(rho, i_prev[None, :, :], axis=0)[0]

    z3 = np.broadcast_to(depth_m[:, None, None], (nlev, ny, nx))
    z_idx = np.take_along_axis(z3, idx_exp, axis=0)[0]
    z_prev = np.take_along_axis(z3, i_prev[None, :, :], axis=0)[0]

    den = rho_idx - rho_prev
    safe_den = np.where(np.abs(den) > 1e-12, den, np.nan)

    with np.errstate(invalid="ignore", divide="ignore"):
        cross = z_prev + (threshold - rho_prev) * (z_idx - z_prev) / safe_den

    cross = np.where(idx == 0, z_idx, cross)
    cross = np.where(has_crossing, cross, np.nan)

    good_surface = np.isfinite(thetao[0, :, :]) & np.isfinite(so[0, :, :])
    cross = np.where(good_surface, cross, np.nan)

    return cross.astype("float32")


def build_comparison_mask(op, mlt):
    """True only where both fields are finite in every collected month."""
    return np.all(np.isfinite(op) & np.isfinite(mlt), axis=0)


def compute_difference_metrics(op_clim, mlt_clim, mask, area, total_ocean_area):
    diff = op_clim - mlt_clim
    valid = (
        mask
        & np.isfinite(op_clim)
        & np.isfinite(mlt_clim)
        & np.isfinite(diff)
        & np.isfinite(area)
    )

    w = area[valid].astype("float64")
    x = op_clim[valid].astype("float64")
    y = mlt_clim[valid].astype("float64")
    d = diff[valid].astype("float64")

    W = np.sum(w)
    bias = np.sum(w * d) / W
    rms = np.sqrt(np.sum(w * d * d) / W)

    mx = np.sum(w * x) / W
    my = np.sum(w * y) / W
    cov = np.sum(w * (x - mx) * (y - my)) / W
    vx = np.sum(w * (x - mx) ** 2) / W
    vy = np.sum(w * (y - my) ** 2) / W
    corr = cov / np.sqrt(vx * vy)

    exceed_area = np.sum(w[np.abs(d) > 20.0])
    exceed_frac = 100.0 * exceed_area / W

    shared_area = W
    shared_pct = 100.0 * W / total_ocean_area

    return {
        "bias": float(bias),
        "rms": float(rms),
        "corr": float(corr),
        "exceed_area": float(exceed_area),
        "exceed_frac": float(exceed_frac),
        "shared_area": float(shared_area),
        "shared_pct": float(shared_pct),
        "cell_count": int(np.sum(mask)),
        "n_valid": int(np.sum(valid)),
    }


def summarize_exceedance(diff, mask, area, lat2d, lon2d):
    """Area-weighted exceedance fractions by latitude band and named basin."""
    valid = mask & np.isfinite(diff) & np.isfinite(area)
    ad = np.abs(diff)
    out = {}

    for low in np.arange(-90.0, 90.0, 10.0):
        high = low + 10.0
        sel = valid & (lat2d >= low) & (lat2d < high)
        w = np.sum(area[sel])
        if w > 0:
            frac = 100.0 * np.sum(area[sel & (ad > 20.0)]) / w
            out[f"lat {low:+.0f} to {high:+.0f}"] = float(frac)

    lon = lon2d % 360.0
    basins = {
        "North Atlantic": (lat2d >= 20.0) & (lat2d <= 80.0) & (lon >= 280.0),
        "North Pacific": (lat2d >= 20.0)
        & (lat2d <= 80.0)
        & (lon >= 100.0)
        & (lon < 280.0),
        "Southern Ocean": lat2d < -40.0,
        "Equatorial band": (lat2d >= -20.0) & (lat2d <= 20.0),
    }
    for name, sel0 in basins.items():
        sel = valid & sel0
        w = np.sum(area[sel])
        if w > 0:
            frac = 100.0 * np.sum(area[sel & (ad > 20.0)]) / w
            out[name] = float(frac)

    return out


def conservative_regrid(field, area, lat2d, lon2d, target_lon, target_lat):
    """
    Conservative area-weighted cell-centre binning to a regular lon/lat grid.
    Source cells are binned by their centres into 1-degree target cells and
    averaged with areacello as the weight.  Used for display only.
    """
    ny, nx = field.shape
    nlat = len(target_lat)
    nlon = len(target_lon)

    lon = lon2d % 360.0
    lat = lat2d

    dlon = target_lon[1] - target_lon[0]
    dlat = target_lat[1] - target_lat[0]
    lon0 = target_lon[0] - 0.5 * dlon
    lat0 = target_lat[0] - 0.5 * dlat

    i = np.floor((lon - lon0) / dlon).astype(int)
    j = np.floor((lat - lat0) / dlat).astype(int)

    valid = (
        np.isfinite(field)
        & np.isfinite(area)
        & (i >= 0)
        & (i < nlon)
        & (j >= 0)
        & (j < nlat)
    )

    out_sum = np.zeros((nlat, nlon), dtype="float64")
    out_w = np.zeros((nlat, nlon), dtype="float64")

    np.add.at(
        out_sum,
        (j[valid], i[valid]),
        field[valid].astype("float64") * area[valid].astype("float64"),
    )
    np.add.at(out_w, (j[valid], i[valid]), area[valid].astype("float64"))

    out = np.full((nlat, nlon), np.nan, dtype="float64")
    good = out_w > 0
    out[good] = out_sum[good] / out_w[good]
    return out

## 1. Direct answer

Yes — the test can be run, and the answer is that a density-criterion MLD computed offline from each model's own `thetao`/`so` largely reproduces the model's published `mlotst`, but **not exactly**: for all six model-and-month combinations the operator MLD is systematically *shallower* than `mlotst` (all biases negative), with weighted RMS differences ranging from 5.1 m to 31.7 m and spatial correlations of 0.938–0.998. Internal consistency, ranked by the mean of the March and September area-weighted RMS difference (smallest = most consistent), is:

1. **CESM2** — mean RMS 6.3 m (7.5 m March, 5.1 m September), r = 0.998/0.998, bias −4.5/−2.6 m
2. **MPI-ESM1-2-LR** — mean RMS 19.2 m (10.8 m March, 27.5 m September), r = 0.995/0.956, bias −0.9/−8.0 m
3. **GFDL-ESM4** — mean RMS 25.5 m (31.7 m March, 19.2 m September), r = 0.938/0.985, bias −11.4/−7.5 m

The residual disagreements are definitional (reference level, displaced-parcel density at local pressure vs. σ0, and MLD-of-monthly-means vs. instantaneous MLD), not model physics errors.

## 2. Methodology as actually executed

**Data and period.** Files were read from `/data1/lorraine-20419/benchmark_cmip6/historical/<model>/<var>/`. For each variable the variant present in the filenames was identified and the most common one retained (all variables resolved to `r1i1p1f1`). `thetao` and `so` (Omon) were opened with `xr.open_mfdataset(combine="by_coords", use_cftime=True, decode_times=True, chunks={"time":1})`; `mlotst` (Omon) and the Ofx fields `areacello` (and `sftof` for CESM2) likewise. The time axis was restricted to `dt.year` 1971–2000 inclusive and the code verified 360 months; `so` and `mlotst` were aligned to the `thetao` time axis with `.sel(time=...)`. March and September indices were selected by `dt.month == 3` and `== 9`, each checked to contain exactly 30 months.

**Grids and levels (no regridding at this stage).** CESM2: curvilinear `nlat`×`nlon` = 384×320, `lev` scaled by 0.01 (60 levels, 5–5375 m), masked by `sftof > 0`. GFDL-ESM4: regular `lat`×`lon` = 180×360, `lev` scale 1.0 (35 levels, 2.5–6500 m). MPI-ESM1-2-LR: curvilinear `j`×`i` = 220×256, `lev` scale 1.0 (40 levels, 6–5720 m). Level order was sorted ascending (`argsort`) and converted to metres below the surface. `areacello` was transposed to (y, x); values with magnitude > 1e10 were set to NaN; for CESM2 cells with `sftof == 0` were additionally set to NaN. Total ocean area = `nansum(areacello)` over the surviving wet cells (CESM2 3.605×10¹⁴ m², GFDL-ESM4 1.453×10¹⁴ m², MPI-ESM1-2-LR 7.846×10¹³ m²).

**Operator MLD.** For every monthly profile and each horizontal column: depth z = −depth_m, p = `gsw.p_from_z(z, lat)`, longitude wrapped to [−180, 180]; `so` treated as practical salinity (units "0.001") and converted with `gsw.SA_from_SP(so, p, lon, lat)`; `thetao` treated as potential temperature and converted along the potential-temperature route with `gsw.CT_from_pt(SA, thetao)`; potential density `gsw.rho(SA, CT, p_ref)` referenced to the pressure of the *shallowest level in each column* (`p_ref = p[0]`), i.e. effectively the surface, not 10 m. The first level where ρ exceeds ρ(surface) + 0.03 kg m⁻³ was located with `argmax` on the boolean condition, and the crossing depth linearly interpolated between that level and the one above (if the threshold is already exceeded at the first level, that level's depth is used). Columns never reaching the threshold, or with missing surface T/S, were left NaN. Fill values were additionally scrubbed with `|x| > 1e10 → NaN` before use.

**Climatology and shared mask.** For each model and month the 30 operator-MLD fields and the 30 `mlotst` fields were stacked; `build_comparison_mask` returns True only where **both** fields are finite in **all 30** instances. The mask was applied to both fields, then the 30 values were averaged with `nanmean` (each month's MLD computed first, then averaged — never averaging T/S first). No day weights were used.

**Metrics.** All statistics used `areacello` as weights on the native grid: weighted bias (operator − `mlotst`), weighted RMS, weighted spatial Pearson correlation (weighted covariance over weighted variances), and the area fraction with |difference| > 20 m expressed as a share of the shared-mask weighted area; the shared-mask area is also reported as a percentage of the model's total ocean area. Cells with non-finite `areacello` (e.g. decoded fill values) drop out of the weighted sums, so the number of cells entering the metrics can be smaller than the mask cell count (GFDL-ESM4: 23 649/24 777 of 42 122/43 259 mask cells; MPI: 18 905/20 783 of 33 260/35 177; CESM2: all mask cells used).

**Display regridding.** Only for Figure 1 (and the cell-by-cell map view) was a common 1° longitude–latitude grid used: source cell centres were binned into 1°×1° target cells and averaged with `areacello` as weight (labelled in the code as a conservative area-weighted cell-centre regrid). Area means, counts and all Step-4 metrics remain on each model's native grid.

## 5. Insights and patterns

- **Sign is consistent and expected.** Every bias is negative: the operator MLD is shallower than `mlotst` in all six combinations. This is the signature of the definitional differences flagged in the analysis plan — the reference is the shallowest model level (effectively the surface) rather than the 10 m often quoted, the criterion is applied to a displaced-parcel density at local pressure rather than a σ0 difference, and the operator is a mean of 30 monthly MLDs rather than a climatological MLD (or a monthly-mean MLD from instantaneous fields). The operator is never expected to reproduce `mlotst` exactly.
- **CESM2 is by far the most internally consistent** (r ≈ 0.998, RMS 5–7 m, exceedance ≤ 2.7 %), and its disagreement is confined almost entirely to the March North Atlantic deep-convection region, where the mixed layer is deep and a 0.03 kg m⁻³ threshold crossing is sensitive to the density formulation.
- **GFDL-ESM4 is the least consistent**, with the largest bias (−11.4 m in March) and RMS (31.7 m in March), and exceedance concentrated in the March North Atlantic (57 % of that basin's area) and in the September Southern Ocean (20 %). The GFDL-ESM4 profile has only 35 levels with coarse near-surface spacing (2.5, 10, 20, 32.5 m …), so the interpolated crossing depth is more strongly quantised than in the finer CESM2 (60 levels) and MPI (40 levels) columns; this is a plausible contributor to the larger RMS in addition to the definitional terms.
- **MPI-ESM1-2-LR shows a strong seasonal asymmetry**: nearly unbiased in March (−0.9 m, RMS 10.8 m, r 0.995) but a −8.0 m bias and 27.5 m RMS in September, driven by the Antarctic/Southern Ocean bands (−80 to −70°S: 50.5 % of area exceeding 20 m).
- **Correlations are high everywhere (≥ 0.938) and RMS is concentrated in a small area fraction** (0.2–15 %), i.e. the two fields agree in pattern almost everywhere and disagree in magnitude only where the mixed layer is deep or the vertical grid is coarse. Any use of `mlotst` as a validation target should therefore expect a shallow bias of a few metres in the mean, with local errors of tens to hundreds of metres in winter deep-mixing regions.
- **Caveat on the area percentages:** the shared-area percentage is relative to `nansum(areacello)` after the code's own masking (`|area| > 1e10 → NaN`, plus the `sftof` wet-cell mask for CESM2). The resulting total ocean areas differ substantially between models (3.605×10¹⁴, 1.453×10¹⁴, 7.846×10¹³ m²), so the "% of ocean" column should be compared across models with that denominator definition in mind; the bias, RMS, correlation and exceedance fractions are unaffected because they are normalised by the same weighted shared area.
