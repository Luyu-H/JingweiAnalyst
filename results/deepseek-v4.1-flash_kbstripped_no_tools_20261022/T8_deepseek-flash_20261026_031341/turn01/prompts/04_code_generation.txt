Important:
- Computation code MUST be complete and standalone
- Let failures raise. Do NOT wrap a step in try/except to record the error and carry on: the run
  then exits cleanly with part of the answer silently missing, and the repair pass never sees the
  problem. If one model or one variable cannot be processed the way you wrote it, the right
  response is to fix the call, not to catch the exception. Only catch one when the question itself
  asks you to tolerate a missing input, and then still leave the failure in a variable the answer
  can report.
- Arrays opened with chunks (xr.open_dataset(..., chunks=...), xr.open_mfdataset) are LAZY
  (dask-backed). Every quantity you want reported must be materialised explicitly with .compute() (or
  float()) into its own small variable, otherwise the downstream step sees a dask placeholder and no
  numbers at all. Large intermediates can stay lazy.
- Regional or global means are area- or volume-weighted: for a CMIP6 model by its own areacello /
  volcello fixed fields, for a regular latitude-longitude grid by the area of each cell. Do not
  average over lat/lon with a plain .mean().
- CESM2 and MPI-ESM1-2-LR are on curvilinear grids: their index dimensions (nlat/nlon, j/i) are NOT
  geographic and cannot be sliced by value with .sel(). Subset them with a mask built from their 2-D
  latitude/longitude coordinates instead.
- CMIP6 concentrations are in mol m-3 (volume basis) while WOA23 and GLODAP are in umol kg-1 (mass
  basis); convert with the in situ density (mol m-3 = umol kg-1 * rho / 1000) before
  comparing them.
- For a region that crosses the dateline (the equatorial Pacific, 120E-280E), mind each product's
  native longitude convention (see the conventions above): such a window is contiguous on a 0-360
  axis but wraps around on a -180-180 one.
- The execution environment runs with keep_attrs enabled, so ordinary xarray operations preserve
  attributes; but when a step changes the physical quantity (a ratio, a difference of unlike
  things), set the new units yourself with .assign_attrs(units=...), or the reported units will be
  wrong.
- Visualization code can reference variables from computation
- Colour limits on a shared scale: take them from a robust percentile of the pooled data, e.g.
  `vmax = float(np.nanpercentile(np.abs(np.concatenate([...])), 98))`, and never from the maximum
  absolute value. A single coastal or marginal-sea cell is routinely an order of magnitude larger
  than the signal, and `vmax = nanmax(abs(...))` then hands the whole scale to that one cell so
  every panel renders as uniform white. Use a diverging map centred on zero for a difference or
  anomaly and a sequential map for a magnitude. When values are clipped, pass `extend='both'` (or
  'max'/'min') so the colourbar shows arrows, and say how they were clipped in the figure title.
- Keep a colourbar label to the quantity and its units, e.g. "SSS bias (psu)", under about 40
  characters. A vertical colourbar label longer than the bar is cut off at both ends in the saved
  image. Notes such as the clipping percentile, "shared scale" or the data source go in the figure
  or panel title, never in the colourbar label.
- Do NOT call tight_layout() after attaching a colorbar to several axes (`fig.colorbar(..., ax=axes)`)
  — it does not know about that colorbar and will lay the panels over it. Either build the figure
  with `plt.subplots(..., constrained_layout=True)` and add no tight_layout at all, or call
  tight_layout BEFORE adding the colorbar.
- Keep annotation off the data: `loc="best"` for a legend, or place it outside the axes. A legend
  pinned to a corner where a curve peaks hides the very feature the panel is there to show.
- A field on a curvilinear grid has 2-D coordinates whose names differ by model. Take them from the
  model's lat_coord / lon_coord in the dataset entry above rather than assuming `lat` / `lon`.
- To map a field on a curvilinear grid (CESM2 or MPI-ESM1-2-LR native output), first put it on a
  regular 1-degree longitude-latitude grid, interpolating from its 2-D latitude/longitude (e.g. with
  scipy.interpolate) (for display only; every reported
  number stays on the native grid) and draw it with `pcolormesh` on the 1-D lon/lat. Do not hand its
  2-D coordinates to `pcolormesh`/`contourf`: the model longitude wraps and jumps at the grid seam,
  which smears the field into horizontal bands and puts it in the wrong place.
- To map a region that crosses the dateline (the North Pacific 110E-100W, the equatorial Pacific

def find_cmip6_files(model, var):
    patterns = []
    if var in ["areacello", "sftof"]:
        patterns.append(f"{var}_Ofx_{model}_historical_*_*.nc")
    elif var == "volcello":
        patterns.append(f"{var}_Ofx_{model}_historical_*_*.nc")
        patterns.append(f"{var}_Omon_{model}_historical_*_*.nc")
    else:
        patterns.append(f"{var}_Omon_{model}_historical_*_*.nc")

    files = []
    for pat in patterns:
        files.extend(glob.glob(os.path.join(CMIP6_ROOT, model, var, pat)))

    if not files:
        dirpath = os.path.join(CMIP6_ROOT, model, var)
        if os.path.isdir(dirpath):
            files = glob.glob(os.path.join(dirpath, "*.nc"))
    return sorted(set(files))


def open_cmip6_var(model, var):

    if not files:

    kwargs = dict(use_cftime=True, decode_times=True)
    if len(files) == 1:

    else:
        if var in ["dissic", "talk", "ph", "thetao", "so"] or (

def compute_density(T, S, depth_m):
    """
    In-situ density (kg m-3) from potential temperature T (degC), practical
    salinity S, and depth (m), using the UNESCO 1983 (EOS-80) equation of
    state.  Pressure is approximated from depth as P[dbar] ~= depth[m],
    then converted to bars for the EOS-80 coefficients.
    """
    T = T.astype(float)
    S = S.astype(float)
    P = (depth_m / 10.0).astype(float)  # dbar -> bar

    T_b, P_b = xr.broadcast(T, P)

    rho0 = (
        999.842594
        + 6.793952e-2 * T_b
        - 9.095290e-3 * T_b**2
        + 1.001685e-4 * T_b**3
        - 1.120083e-6 * T_b**4
        + 6.536332e-9 * T_b**5
        + (
            0.824493
            - 4.0899e-3 * T_b
            + 7.6438e-5 * T_b**2
            - 8.2467e-7 * T_b**3
            + 5.3875e-9 * T_b**4
        )
        * S
        + (-5.72466e-3 + 1.0227e-4 * T_b - 1.6546e-6 * T_b**2) * S**1.5
        + 4.8314e-4 * S**2
    )

    K0 = (
        19652.21
        + 148.4206 * T_b
        - 2.327105 * T_b**2
        + 1.360477e-2 * T_b**3
        - 5.155288e-5 * T_b**4
        + (
            54.6746
            - 0.603459 * T_b
            + 1.09987e-2 * T_b**2
            - 6.1670e-5 * T_b**3
        )
        * S
        + (7.944e-2 + 1.6483e-2 * T_b - 5.3009e-4 * T_b**2) * S**1.5
    )

    K1 = (
        3.239908
        + 1.43713e-3 * T_b
        + 1.16092e-4 * T_b**2
        - 5.77905e-7 * T_b**3
        + (
            2.2838e-3
            - 1.0981e-5 * T_b
            - 1.6078e-6 * T_b**2
        )
        * S
        + 1.91075e-4 * S**1.5
    )

    K2 = (
        8.50935e-5
        - 6.12293e-6 * T_b
        + 5.2787e-8 * T_b**2
        + (-9.9348e-7 + 2.0816e-8 * T_b + 9.1697e-10 * T_b**2) * S
    )

    K = K0 + P_b * K1 + P_b**2 * K2
    rho = rho0 / (1.0 - P_b / K)
    return rho


def regrid_vertical(da, depth_name, target_depths):
    da = da.compute()
    return da.interp(
        {depth_name: target_depths},
        kwargs={"fill_value": "extrapolate"},

def regrid_regular_to_glodap(da, lat_name, lon_name, target_lat, target_lon):
    da = da.compute()
    lon = da[lon_name]
    lon_shift = lon % 360.0
    lon_shift = xr.where(lon_shift < 20.5, lon_shift + 360.0, lon_shift)
    da = da.assign_coords({lon_name: lon_shift}).sortby(lon_name)
    out = da.interp(
        {lat_name: target_lat, lon_name: target_lon},
        method="linear",
    )
    out = out.rename({lat_name: "lat", lon_name: "lon"})
    return out


def regrid_curvilinear_to_glodap(da, lat2d, lon2d, target_lat, target_lon):
    da = da.compute()
    lat = lat2d.values.ravel()
    lon = lon2d.values.ravel() % 360.0
    lon = np.where(lon < 20.5, lon + 360.0, lon)
    vals = da.values.ravel()

    valid = np.isfinite(vals) & np.isfinite(lat) & np.isfinite(lon)
    points = np.column_stack([lat[valid], lon[valid]])
    values = vals[valid]

    target_lat_mesh, target_lon_mesh = np.meshgrid(
        target_lat, target_lon, indexing="ij"
    )
    grid = griddata(
        points,
        values,
        (target_lat_mesh, target_lon_mesh),
        method="linear",
    )
    return xr.DataArray(
        grid,
        coords={"lat": target_lat, "lon": target_lon},
        dims=("lat", "lon"),
    )


def area_weighted_mean_0_50(da, depth_name, area, depth_max=50.0):
    da = da.compute()
    area = area.compute()
    da_sub = da.sel({depth_name: da[depth_name] <= depth_max})
    da_sub_b, area_b = xr.broadcast(da_sub, area)
    mask = np.isfinite(da_sub_b) & np.isfinite(area_b)
    prod = (da_sub_b * area_b).where(mask)
    num = float(prod.sum().compute())
    den = float(area_b.where(mask).sum().compute())
    return num / den
