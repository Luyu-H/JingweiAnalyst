- For each source, the calendar month of largest standard deviation and its value, the calendar month of smallest standard deviation, and the largest-to-smallest ratio to 2 decimal places; and whether each model reproduces the observed peak month and strength of seasonal phase locking.
- For each source, the number and the percentage (to 1 decimal place) of months whose Nino 3.4 anomaly strictly exceeds 1.0 degrees Celsius in absolute value.

Also load each CMIP6 model’s published `areacello` fixed field for weighting. Do not substitute `thetao` for `tos`.
- Note [cmip6-tos-bulk-top-cell]: use `tos` directly with the default `depth_level=None`; it is the bulk temperature of the top model cell, not a skin value.
- Note [cmip6-static-grid-fields]: use each model’s published `areacello` as the area weight, with zero/missing values over land, and report the origin recorded in `attrs['area_source']` when it feeds the regional average.
- Note [cmip6-grid-labels]: GFDL-ESM4 is on the archive `gr` 1x1 degree regridded grid with a regridded land-sea mask; CESM2 and MPI-ESM1-2-LR native horizontal resolutions differ by about 2.5x, so narrow features are not comparable in amplitude across grids.

2. For each of the four sources, compute the monthly Nino 3.4 regional mean SST over 5S-5N, 170W-120W on that source’s own grid. - Note [omip-weighted-means-and-integrals]: the Nino 3.4 average must be area-weighted with weights restricted to the same valid cells as the data; an unweighted mean over latitude/longitude is wrong on a curvilinear grid.
- Note [omip-native-grid-vs-regridded]: compute every index and statistic on each source’s own grid with its own cell areas; no regridding is needed, so no regrid method is quoted.

3. Build each source’s monthly Nino 3.4 anomaly series over 1950-01 to 2014-12 by subtracting that source’s own 1950-2014 monthly climatology, matching each month to the climatology of its own calendar month. Record and report the climatology and baseline used for each source.

Also compute, for each source, the population standard deviation of the anomaly for each of the 12 calendar months, identify the calendar month of largest and smallest standard deviation, and compute the largest-to-smallest ratio. Compare only these statistics between models and observations.
- Note [cmip6-experiments-historical-ssp245]: coupled historical runs have their own internal variability, so compare only statistics and never individual years or event timing; with one member per model, differences in amplitude cannot be split into forced versus internal-variability parts.

5. For each source, count the months over 1950-01 to 2014-12 whose Nino 3.4 anomaly strictly exceeds 1.0 degree Celsius in absolute value, and compute the percentage of the 780 months to 1 decimal place, using the strict |anomaly| > 1.0 criterion from [anomaly-baselines-and-climate-indices].

        "grid_label": "gn",
        "y_dim": "nlat",
        "x_dim": "nlon",
        "lat_coord": "lat",
        "lon_coord": "lon",
        "ocean_mask_from": "sftof",
    },
    "GFDL-ESM4": {
        "grid_label": "gr",
        "y_dim": "lat",
        "x_dim": "lon",
        "lat_coord": "lat",
        "lon_coord": "lon",
        "ocean_mask_from": None,
    },
    "MPI-ESM1-2-LR": {
        "grid_label": "gn",
        "y_dim": "j",
        "x_dim": "i",
        "lat_coord": "latitude",

        "ocean_mask_from": None,

def find_cmip_files(model, variable, table, grid):
    d = os.path.join(root_cmip, model, variable)
    pattern = os.path.join(d, f"{variable}_{table}_{model}_historical_*_{grid}*.nc")
    return sorted(glob.glob(pattern))


def parse_variant(files):
    for f in files:
        m = re.search(r"_historical_(r\d+i\d+p\d+f\d+)_", os.path.basename(f))
        if m:
            return m.group(1)
    return None


def open_cmip_dataset(files, **kwargs):
    if not files:
        raise FileNotFoundError("No CMIP6 files found")
    dss = [xr.open_dataset(f, **kwargs) for f in files]
    if len(dss) == 1:
        return dss[0]
    ds = xr.concat(dss, dim="time")
    if "time" in ds.coords:
        ds = ds.sortby("time")
    return ds


def select_years_months(da, y0, y1):
    time = da["time"]
    ym = time.dt.year.values.astype(int) * 100 + time.dt.month.values.astype(int)
    idx = np.where((ym >= y0 * 100 + 1) & (ym <= y1 * 100 + 12))[0]
    return da.isel(time=idx)


def get_coord(ds, name):
    if name in ds.coords:
        return ds.coords[name]
    if name in ds.data_vars:
        return ds[name]
    raise KeyError(f"Coordinate {name!r} not found")


def squeeze_singletons(da, keep_dims):
    for d in list(da.dims):
        if d not in keep_dims and da.sizes[d] == 1:
            da = da.isel({d: 0}, drop=True)
    return da


def compute_nino34_cmip(model):
    info = model_info[model]
    grid = info["grid_label"]

    files_all = find_cmip_files(model, "tos", "Omon", grid)
    if not files_all:
        raise FileNotFoundError(f"No tos files for {model}")
    variant = parse_variant(files_all)
    files = [f for f in files_all if variant in os.path.basename(f)] if variant else files_all
    if not files:
        files = files_all

    ds = open_cmip_dataset(files, use_cftime=True, decode_times=True)
    tos = ds["tos"]
    tos = select_years_months(tos, 1950, 2014).sortby("time")
    tos = squeeze_singletons(tos, keep_dims=("time", info["y_dim"], info["x_dim"]))
    if tos.sizes["time"] != 780:
        raise ValueError(f"{model} tos has {tos.sizes['time']} months, expected 780")
    extra = [d for d in tos.dims if d not in ("time", info["y_dim"], info["x_dim"])]
    if extra:
        raise ValueError(f"Unexpected dimensions in {model} tos: {extra}")

    area_files_all = find_cmip_files(model, "areacello", "Ofx", grid)
    if not area_files_all:
        raise FileNotFoundError(f"No areacello files for {model}")
    area_files = [f for f in area_files_all if variant in os.path.basename(f)] if variant else area_files_all
    if not area_files:
        area_files = area_files_all[:1]
    area_ds = open_cmip_dataset(area_files, use_cftime=True, decode_times=True)
    area = area_ds["areacello"]
    if "time" in area.dims:
        area = area.isel(time=0, drop=True)
    area = squeeze_singletons(area, keep_dims=(info["y_dim"], info["x_dim"]))
    area = area.where(area > 0, 0.0).fillna(0.0)

    if info.get("ocean_mask_from") == "sftof":
        sftof_files_all = find_cmip_files(model, "sftof", "Ofx", grid)
        if not sftof_files_all:
            raise FileNotFoundError(f"sftof required for {model} but not found")
        sftof_files = [f for f in sftof_files_all if variant in os.path.basename(f)] if variant else sftof_files_all
        if not sftof_files:
            sftof_files = sftof_files_all[:1]
        sftof_ds = open_cmip_dataset(sftof_files, use_cftime=True, decode_times=True)
        sftof = sftof_ds["sftof"]
        if "time" in sftof.dims:
            sftof = sftof.isel(time=0, drop=True)
        sftof = squeeze_singletons(sftof, keep_dims=(info["y_dim"], info["x_dim"]))
        area = area.where((sftof > 0) & sftof.notnull(), 0.0)

    extra_area = [d for d in area.dims if d not in (info["y_dim"], info["x_dim"])]
    if extra_area:
        raise ValueError(f"Unexpected dimensions in {model} areacello: {extra_area}")

    lat = get_coord(ds, info["lat_coord"])
    lon = get_coord(ds, info["lon_coord"])
    lon360 = lon % 360.0
    region = (lat >= -5.0) & (lat <= 5.0) & (lon360 >= 190.0) & (lon360 <= 240.0)

    weights = area * region
    valid = tos.notnull()
    w = weights.where(valid, 0.0)
    num = (tos.fillna(0.0) * w).sum(dim=(info["y_dim"], info["x_dim"]))
    den = w.sum(dim=(info["y_dim"], info["x_dim"]))
    series = (num / den).where(den > 0)
    series = series.compute()
    series.name = "nino34_sst"
    return series, variant


def compute_nino34_ersst():
    ds = xr.open_dataset(ersst_path, use_cftime=True, decode_times=True)
    sst = ds["sst"]
    sst = select_years_months(sst, 1950, 2014).sortby("time")
    if sst.sizes["time"] != 780:
        raise ValueError(f"ERSSTv5 sst has {sst.sizes['time']} months, expected 780")

    lat = sst["lat"]
    lon = sst["lon"] % 360.0
    region = (lat >= -5.0) & (lat <= 5.0) & (lon >= 190.0) & (lon <= 240.0)

    w2d = xr.DataArray(
        np.cos(np.deg2rad(lat.values))[:, None] * np.ones((lat.size, lon.size)),
        dims=("lat", "lon"),
        coords={"lat": lat, "lon": sst["lon"]},
    )
    weights = w2d * region
    valid = sst.notnull()
    w = weights.where(valid, 0.0)
    num = (sst.fillna(0.0) * w).sum(dim=("lat", "lon"))
    den = w.sum(dim=("lat", "lon"))
    series = (num / den).where(den > 0)
    series = series.compute()
    series.name = "nino34_sst"
    return series, None

def compute_stats(series, source):
    vals = np.asarray(series.values, dtype=float)
    months = np.asarray(series.time.dt.month.values, dtype=int)
    if len(vals) != 780:
        raise ValueError(f"{source} has {len(vals)} values, expected 780")

    clim = np.array([np.nanmean(vals[months == m]) for m in range(1, 13)], dtype=float)
    anomaly = vals - clim[months - 1]

    std_all = float(np.nanstd(anomaly, ddof=0))
    std_month = np.array(
        [np.nanstd(anomaly[months == m], ddof=0) for m in range(1, 13)],
        dtype=float,
    )

    peak_idx = int(np.nanargmax(std_month))
    min_idx = int(np.nanargmin(std_month))
    peak_month = peak_idx + 1
    min_month = min_idx + 1
    peak_value = float(std_month[peak_idx])
    min_value = float(std_month[min_idx])
    ratio = float(peak_value / min_value) if min_value > 0 else np.nan

    n_exceed = int(np.sum(np.abs(anomaly) > 1.0))
    pct = float(100.0 * n_exceed / len(anomaly))

    decimal_year = (
        series.time.dt.year.values.astype(float)
        + (series.time.dt.month.values.astype(float) - 1.0) / 12.0
    )

    return {
        "source": source,
        "values": vals,
        "months": months,
        "climatology": clim,
        "anomaly": anomaly,
        "std_all": std_all,
        "std_month": std_month,
        "peak_month": peak_month,
        "peak_value": peak_value,
        "min_month": min_month,
        "min_value": min_value,
        "ratio": ratio,
        "n_exceed": n_exceed,
        "pct": pct,
        "decimal_year": decimal_year,
    }

## Visualization descriptions

**Figure 1** is a line plot of the seasonal cycle of Amplitude: calendar month January-December on the x-axis and the monthly Nino 3.4 anomaly standard deviation in degC on the y-axis. Four curves are shown on one axis, with ERSSTv5 visually distinct from the three models. Each curve’s peak month is marked. The intended logic is to compare the monthly amplitude cycle and the timing of maximum amplitude across observations and models.

**Figure 2** consists of four stacked panels in the order ERSSTv5, CESM2, GFDL-ESM4, MPI-ESM1-2-LR. The panels share one time axis over 1950-2014 and an identical y-axis range that contains all four anomaly series. Each panel shows that source’s monthly Nino 3.4 anomaly series, with +1.0 and -1.0 degC reference levels marked and the panel annotated with the full-period standard deviation and exceedance count/percentage. The intended logic is to display the anomaly time series on a common scale while separating the sources into panels, allowing amplitude and exceedance behavior to be compared without implying event-by-event correspondence.

## Interpretation and insights

- **MPI-ESM1-2-LR** has near-observed full-period ENSO amplitude in Nino 3.4 and the smallest absolute amplitude bias. Its exceedance percentage, 25.5%, is also closest to the observed 21.8%, though it is still somewhat higher.
- **GFDL-ESM4** has a modest positive amplitude bias, with a standard deviation of 1.00 degC versus 0.85 degC observed. Its exceedance percentage is higher than observed, and it matches the observed December peak month but has weaker maximum-to-minimum seasonal contrast.
- **CESM2** clearly overestimates Nino 3.4 amplitude in this single historical member: its full-period standard deviation is 1.29 degC, its amplitude ratio is 1.52, and 46.2% of months exceed |1.0| degC. Its seasonal peak occurs in January rather than December.
- All models have positive full-period amplitude bias in this comparison. However, because each model has only one member, these differences cannot be cleanly attributed to model formulation versus internal variability.
- The seasonal phase-locking ratio is lower in all models than in ERSSTv5 by this metric, suggesting weaker seasonal amplitude contrast even where the peak month is correctly reproduced.
- Comparisons are statistical only and should not be interpreted as matching individual ENSO events or years. Different native/archive grids and the use of bulk top-cell `tos` versus an observational SST product also affect detailed amplitude comparisons.
