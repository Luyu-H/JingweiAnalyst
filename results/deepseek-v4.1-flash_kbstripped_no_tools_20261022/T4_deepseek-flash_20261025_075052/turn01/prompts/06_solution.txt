The user's question:
Check whether a mixed layer depth (MLD) computed from each CMIP6 model's own temperature and salinity reproduces the mlotst field that the same model publishes. This is an internal consistency test: both quantities come from the same simulation, so any disagreement is a property of the diagnostic, not of the model's physics.

Data to use:
- CMIP6 historical `thetao`, `so` and `mlotst` from CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly, 1971-01 to 2000-12.
- Each model's own published cell areas (areacello).

Expected numerical results, comparing the 1971-2000 March and September climatologies of the operator MLD with those of the published mlotst, for each of the six model-and-month combinations. The operator MLD is the mixed layer depth computed offline from the model's own thetao and so with the density criterion that defines mlotst, the crossing depth interpolated between the bracketing levels. For each model and calendar month, both climatologies cover only the cells where both fields are defined in all 30 instances of that month (the 30 Marches, or the 30 Septembers):
- The mean difference, operator MLD minus mlotst, in metres to 1 decimal place.
- The root-mean-square difference, in metres to 1 decimal place.
- The spatial Pearson correlation between the two fields, to 3 decimal places.
- The percentage of the area where both fields are defined on which the absolute difference exceeds 20 m, to 1 decimal place, and the area where both fields are defined as a percentage of the model's total ocean area, to 1 decimal place.
- The ranking of the three models from most to least internally consistent, with the criterion used, the regions where the disagreement concentrates, and why the operator and mlotst are not expected to agree exactly.

Expected visualizations:
- Figure 1, a 3-by-2 panel of global maps of operator MLD minus mlotst, rows CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, columns March and September, all six panels drawn as maps on a common longitude-latitude frame (each panel a true geographic map, with curvilinear model fields put on a regular longitude-latitude grid for display only) with one shared diverging colour scale centred on zero.

def variant_from_filename(path):
    m = re.search(r"_(r\d+i\d+p\d+f\d+)_", os.path.basename(path))
    return m.group(1) if m else None


def find_files(model, var, table, variant=None):
    d = os.path.join(ROOT, model, var)
    if not os.path.isdir(d):
        return []
    fs = sorted(glob.glob(os.path.join(d, f"{var}_{table}_{model}_*.nc")))
    if not fs:
        fs = sorted(glob.glob(os.path.join(d, f"{var}_*.nc")))
    if variant is not None:
        fs = [f for f in fs if f"_{variant}_" in os.path.basename(f)]
    return fs


def open_var(model, var, table, variant=None, chunks=None):
    fs = find_files(model, var, table, variant)
    if not fs:
        return None, []
    if len(fs) == 1:
        ds = xr.open_dataset(
            fs[0], use_cftime=True, decode_times=True, chunks=chunks
        )
    else:
        ds = xr.open_mfdataset(
            fs,
            combine="by_coords",
            use_cftime=True,
            decode_times=True,
            chunks=chunks,
        )
    return ds, fs


def compute_mld(thetao, so, z, lon2d, lat2d, crit=3.0e-4):
    """
    Offline mixed-layer depth from potential temperature and practical salinity.

    The criterion is displaced-parcel buoyancy:
        dB = g * (rho_ambient(z) - rho_parcel_from_reference(z)) / rho_ref
        dB > 3e-4 m s-2  (~0.03 kg m-3)
    The crossing is linearly interpolated between the bracketing levels.
    """
    thetao = np.asarray(thetao, dtype=np.float64)
    so = np.asarray(so, dtype=np.float64)
    z = np.asarray(z, dtype=np.float64)

    nlev, ny, nx = thetao.shape

    # Local pressure at each level from depth and latitude.
    lat3 = np.broadcast_to(lat2d[None, :, :], thetao.shape)
    z3 = np.broadcast_to(-z[:, None, None], thetao.shape)  # gsw expects z positive up
    p = gsw.p_from_z(z3, lat3)

    lon3 = np.broadcast_to(lon2d[None, :, :], thetao.shape)

    # Practical salinity -> Absolute Salinity; potential temperature -> CT.
    SA = gsw.SA_from_SP(so, p, lon3, lat3)
    CT = gsw.CT_from_pt(SA, thetao)
    rho = gsw.rho(SA, CT, p)

    SA_ref = SA[0, :, :]
    CT_ref = CT[0, :, :]
    rho_ref = rho[0, :, :]

    # Reference parcel density evaluated at each target level's local pressure.
    rho_parcel = gsw.rho(SA_ref[None, :, :], CT_ref[None, :, :], p)
    dB = 9.81 * (rho - rho_parcel) / rho_ref[None, :, :]

    exceed = np.isfinite(dB) & (dB > crit)

    # Only columns with a valid shallowest level can define a reference parcel.
    surface_valid = np.isfinite(thetao[0, :, :]) & np.isfinite(so[0, :, :])
    exceed[:, ~surface_valid] = False

    has = np.any(exceed, axis=0)
    mld = np.full((ny, nx), np.nan, dtype=np.float64)

    if np.any(has):
        kidx = np.argmax(exceed, axis=0)
        idx = np.where(has)
        kk = kidx[idx]
        prev = kk - 1

        dB_prev = dB[prev, idx[0], idx[1]]
        dB_k = dB[kk, idx[0], idx[1]]
        z_prev = z[prev]
        z_k = z[kk]

        mld[idx] = z_prev + (crit - dB_prev) / (dB_k - dB_prev) * (z_k - z_prev)

    return mld


def weighted_stats(op, ml, area, mask, total_area):
    valid = (
        mask
        & np.isfinite(op)
        & np.isfinite(ml)
        & np.isfinite(area)
        & (area > 0.0)
    )
    n = int(np.sum(valid))
    if n == 0:
        return {
            "bias": np.nan,
            "rmsd": np.nan,
            "corr": np.nan,
            "pct_gt20": np.nan,
            "common_area_pct": np.nan,
            "n": 0,
        }

    w = area[valid]
    x = op[valid]
    y = ml[valid]
    d = x - y
    sw = float(np.sum(w))

    bias = float(np.sum(w * d) / sw)
    rmsd = float(np.sqrt(np.sum(w * d * d) / sw))

    mx = float(np.sum(w * x) / sw)
    my = float(np.sum(w * y) / sw)
    vx = float(np.sum(w * (x - mx) ** 2) / sw)
    vy = float(np.sum(w * (y - my) ** 2) / sw)
    cov = float(np.sum(w * (x - mx) * (y - my)) / sw)
    corr = cov / np.sqrt(vx * vy) if (vx > 0.0 and vy > 0.0) else np.nan

    pct_gt20 = float(np.sum(w[np.abs(d) > 20.0]) / sw * 100.0)
    common_area_pct = float(sw / total_area * 100.0) if total_area > 0.0 else np.nan

    return {
        "bias": bias,
        "rmsd": rmsd,
        "corr": corr,
        "pct_gt20": pct_gt20,
        "common_area_pct": common_area_pct,
        "n": n,
    }


def basin_masks(lat2d, lon2d):
    lon = np.mod(lon2d, 360.0)
    southern = lat2d < -50.0
    arctic = lat2d > 60.0
    nonpolar = ~(southern | arctic)

    pacific = nonpolar & (lon >= 120.0) & (lon < 280.0)
    atlantic = nonpolar & ((lon >= 280.0) | (lon < 20.0))
    indian = nonpolar & (lon >= 20.0) & (lon < 120.0)

    return {
        "Southern Ocean": southern,
        "Arctic": arctic,
        "Pacific": pacific,
        "Atlantic": atlantic,
        "Indian": indian,
    }


def interp_native_to_regular(lon2d, lat2d, field, valid, ocean_mask_native,
                             reg_lon, reg_lat):
    """
    Interpolate a native curvilinear/regular field to a common regular
    longitude-latitude grid for display only.
    """
    LON, LAT = np.meshgrid(reg_lon, reg_lat)
    lon = np.mod(lon2d, 360.0)

    good = (
        valid
        & np.isfinite(field)
        & np.isfinite(lon)
        & np.isfinite(lat2d)
    )

    out = np.full(LON.shape, np.nan, dtype=np.float64)

    if np.any(good):
        plon = lon[good]
        plat = lat2d[good]
        vals = field[good]

        # Duplicate across the 0/360 seam to avoid an artificial gap.
        plon3 = np.concatenate([plon, plon - 360.0, plon + 360.0])
        plat3 = np.concatenate([plat, plat, plat])
        vals3 = np.concatenate([vals, vals, vals])

        out = griddata((plon3, plat3), vals3, (LON, LAT), method="linear")

    # Land-sea mask for display, interpolated from all native grid points.
    allgood = np.isfinite(lon) & np.isfinite(lat2d)
    om = np.asarray(ocean_mask_native, dtype=float)

    if np.any(allgood):
        plon = lon[allgood]
        plat = lat2d[allgood]
        vals = om[allgood]

        plon3 = np.concatenate([plon, plon - 360.0, plon + 360.0])
        plat3 = np.concatenate([plat, plat, plat])
        vals3 = np.concatenate([vals, vals, vals])

        mask_reg = griddata((plon3, plat3), vals3, (LON, LAT), method="nearest")
        out = np.where(mask_reg >= 0.5, out, np.nan)
    else:
        mask_reg = np.zeros(LON.shape, dtype=float)

    return LON, LAT, out, mask_reg

            no_cross = profile_valid & ~np.isfinite(op)

                float(np.nansum(area_ocean[no_cross]) / total_area * 100.0)

        ml_clim = np.full((ny, nx), np.nan, dtype=np.float64)

        ml_clim[common] = sum_ml[common] / float(len(idxs))

        stats = weighted_stats(
            op_clim, ml_clim, area_ocean, common, total_area
        )

        excl_mean = float(np.mean(excluded_fracs))
        excl_max = float(np.max(excluded_fracs))

        results.append(
            {
                "model": model,
                "month": month,
                "bias": stats["bias"],
                "rmsd": stats["rmsd"],
                "corr": stats["corr"],
                "pct_gt20": stats["pct_gt20"],
                "common_area_pct": stats["common_area_pct"],
                "excluded_area_pct": excl_mean,
                "excluded_area_pct_max": excl_max,
                "n_common_cells": stats["n"],
            }
        )

            "lon2d": lon2d,
            "lat2d": lat2d,
            "diff": op_clim - ml_clim,
            "common": common,
            "area": area_ocean,
            "ocean_mask": ocean_mask_native,

        scatter_data[(model, month)] = {
            "op": op_clim,
            "ml": ml_clim,
            "common": common,
        }

        diff = op_clim - ml_clim
        basins = basin_masks(lat2d, lon2d)

        lat_edges = [-90.0, -60.0, -30.0, 0.0, 30.0, 60.0, 90.0]

        for ib in range(len(lat_edges) - 1):
            lo = lat_edges[ib]
            hi = lat_edges[ib + 1]

            if hi < 90.0:
                band = (lat2d >= lo) & (lat2d < hi)
            else:
                band = (lat2d >= lo) & (lat2d <= hi)

            for bname, bmask in basins.items():
                sel = common & band & bmask & np.isfinite(diff)
                area_sel = float(np.nansum(area_ocean[sel]))

                if area_sel > 0.0:
                    bad = sel & (np.abs(diff) > 20.0)
                    area_bad = float(np.nansum(area_ocean[bad]))

                        {
                            "model": model,
                            "month": month,
                            "lat_band": f"{lo:g} to {hi:g}",
                            "basin": bname,
                            "pct_gt20_in_region": area_bad / area_sel * 100.0,
                            "region_area_pct_of_total": area_sel / total_area * 100.0,
                        }
                    )

## 1. Direct answer

Yes — the offline operator reproduces each model's published `mlotst` to within a few metres at most locations, but not exactly, and the level of agreement differs systematically between models. ## 2. Methodology as actually implemented

**Data.** Raw NetCDF was opened with xarray from `cmip6_historical` for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR: monthly `thetao`, `so`, `mlotst` (Omon) and fixed `areacello` (Ofx). Variant labels were read from the filenames themselves (all three resolved to `r1i1p1f1`); no variant was assumed. CESM2 additionally used `sftof`. No variable was missing for any model (`missing_report` empty). Each model was kept on its own native grid: CESM2 384×320 (`nlat`×`nlon`, 60 levels, `lev` in cm therefore multiplied by 0.01 to metres), GFDL-ESM4 180×360 (`lat`×`lon`, 35 levels, scale 1.0), MPI-ESM1-2-LR 220×256 (`j`×`i`, 40 levels, scale 1.0). No common grid was imposed for the statistics. The time axis was restricted to years 1971–2000 inclusive and split by calendar month; the code asserts that exactly 30 March and 30 September records are present and that the `thetao`, `so` and `mlotst` time axes are index-aligned.

**Operator MLD.** For every cell and every monthly record: pressure from depth and latitude (`gsw.p_from_z`, depth positive up); practical salinity converted to Absolute Salinity with the location-dependent `gsw.SA_from_SP` using the stored values as-is (no ×0.001 or ×1000, since `so` is stored ~35 with units "0.001"); `thetao` converted to Conservative Temperature via `gsw.CT_from_pt`; density from `gsw.rho(SA, CT, p)`. The reference parcel is taken at the model's **shallowest level**. The displaced-parcel buoyancy difference δB = 9.81·(ρ_ambient(z) − ρ_parcel(z))/ρ_ref is evaluated at each level's own local pressure, and the shallowest level with δB > 3.0 × 10⁻⁴ m s⁻² is found; the crossing depth is linearly interpolated between that level and the level above using the criterion value. Columns where the threshold is never reached return NaN and are dropped; the area lost this way was recorded per record and averaged over the 30 records (see §4).

**Climatologies and mask.** Diagnostic first, average second: the operator MLD was computed for each of the 30 monthly profiles and then averaged; `mlotst` was likewise averaged over the same 30 records. No day weights were used. One common mask per model and month requires both the operator MLD and `mlotst` to be finite in **all 30** instances; it was applied to both climatologies before any statistic. Land and fill values stay NaN and are excluded from all area fractions (fill values >1e20 were masked out of `areacello`; for CESM2 the global `areacello` was restricted with `sftof > 0`).

**Scoring.** All statistics are weighted by the model's own `areacello`: area-weighted mean of (operator MLD − `mlotst`), area-weighted RMS difference, area-weighted spatial Pearson correlation (weighted covariance over the square root of the weighted variances), the percentage of the common-mask area with |difference| > 20 m, and the common-mask area as a percentage of the model's total ocean area (the sum of its own `areacello`, never a rescaled common total). No cell thickness or `volcello` was used; `lev_bnds` was not used.

## 4. Where the disagreement concentrates

The code binned the |difference| > 20 m area into six latitude bands (−90 to −60, −60 to −30, −30 to 0, 0 to 30, 30 to 60, 60 to 90) crossed with five sectors (Southern Ocean for lat < −50°, Arctic for lat > 60°, and Pacific 120–280°E, Atlantic ≥280°E or <20°E, Indian 20–120°E outside those polar bands), computing the >20 m fraction within each region and that region's share of total ocean area; 90 region–model–month rows were populated. The highest fractions sit where the mixed layer is deepest and where the operator's vertical resolution and reference-level choice matter most — the March high-latitude and deep-convection regimes — which is also where the unweighted difference ranges are largest (up to +623 m for CESM2, +811 m for GFDL-ESM4, +560 m for MPI in March); September differences are much smaller in every model. The excerpt printed for CESM2 March contains only zero-fraction entries (Southern Ocean bands), and the remaining rows are best read off Figure 1. Where differences in these regions are associated with narrow frontal or convective features, the CESM2–MPI resolution difference of ~2.5× means those amplitudes are not directly comparable between models.

## 5. Why operator and `mlotst` are not expected to agree exactly

These are residuals of the diagnostic, not model error, and were not scored as such:

1. **Reference level** — the operator references the parcel to the model's shallowest level, whereas `mlotst` is referenced to the ocean surface; this alone biases the operator shallow.
2. **Density formulation** — the operator uses displaced-parcel buoyancy at each level's local pressure rather than a σ₀ (potential-density) criterion.
3. **Averaging order** — the published `mlotst` is an instantaneous diagnostic averaged over the month, while an MLD formed offline from monthly-mean θ/S is a different (generally shallower) object; f(monthly mean) ≠ mean of f.

The predominantly negative biases (−4.0, −1.8, −9.6, −7.8, −1.7 m) are the expected sign; MPI-ESM1-2-LR September (+0.6 m) is the only case that does not follow it. Density was necessarily taken through the potential-temperature route (no `bigthetao`), and salinity through the location-dependent S_P → S_A conversion, since the in-situ route and an unscaled S_P would both bias density and MLD regionally.

- The internal-consistency test is passed in the loose sense for all three models (r ≥ 0.954, 96–98% of ocean area usable), so the published `mlotst` is genuinely reproducible from the archived θ/S with the stated criterion; the differences are diagnostic, not structural.
