Plan from the previous step:
1. Open the raw files and cut the analysis window. Datasets: `ersst` (`sst`, monthly 1950-01 to 2014-12 only); `cmip6_historical` (`tos` for CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, monthly 1950-01 to 2014-12; report any model that does not publish `tos` as missing); `cpc_indices` (product `pdo`, monthly, 1950-01 to 2014-12). Keep everything on the native grids at this stage and keep each source's own land/ice cell availability; no shared mask is imposed yet.

2. Bilinear regridding onto the 1-degree grid. Datasets: `cmip6_historical` `tos` (all three models) and `ersst` `sst`, all interpolated bilinearly onto a common 1-degree longitude/latitude grid over the PDO domain. ERSSTv5 is already 1-degree, so it is used as is.
   - Note [cmip6-grid-labels]: GFDL-ESM4 `tos` is already `gr`, i.e. remapped (conserve_order1) onto 1 degree at the archive, so its "native" numbers are archive-grid numbers only approximately conservative; CESM2 (~100 km) and MPI-ESM1-2-LR (~250 km) differ by about 2.5x in resolution.

3. Subset the PDO domain and build the analysis fields. Datasets: regridded `cmip6_historical` `tos`, `ersst` `sst`. Select 20N-70N, 110E-100W (i.e. 110E to 260E across the dateline) for each of the four fields. Note [cmip6-tos-bulk-top-cell]: `tos` is the bulk temperature of the top model cell (CESM2 0-10 m, GFDL-ESM4 0-2 m, MPI-ESM1-2-LR 0-12 m), not a skin value, and sea-ice-covered cells hold under-ice water near freezing rather than missing data, so ocean/ice masks must be made consistent before any model-minus-observation differencing.

4. Remove the seasonal cycle: for each grid cell of each source compute the 1950-2014 climatology of each calendar month and subtract it from that month's values, giving monthly SST anomalies for ERSSTv5 and each model.
   - Note [monthly-means-are-time-averages]: each calendar month's climatology is the plain mean of that month's values over the 1950-2014 years - no day weighting enters a monthly climatology.
   - Note [anomaly-baselines-and-climate-indices]: each model's anomaly is taken against its own 1950-2014 climatology of the same calendar month (never an observed climatology, which would put the model's mean-state bias into the index); the baseline used must be stated, and any offset between the ERSSTv5-derived index and the published `pdo` (which is built on its own baseline) is a baseline difference, not an error.

5. Leading EOF per source. Datasets: the four anomaly fields from step 4. Weight each grid cell by sqrt(cos(latitude)), form the time-by-space anomaly matrix, and take the leading mode by SVD, separately for ERSSTv5, CESM2, GFDL-ESM4 and MPI-ESM1-2-LR, each on its own available cells (no common mask). Explained variance = percentage of the total weighted anomaly variance captured by mode 1.
   - Note [eof-modes-and-pdo-index]: weight cells by sqrt(cos(latitude)) before the EOF, and apply the sign convention positive index = negative SST anomalies in the central/western North Pacific to both pattern and index (flip the SVD sign if needed).

6. Regression pattern, amplitude and dispersion. Datasets: the anomaly fields and standardized leading principal components from step 5. Regress the anomalies at every grid cell onto the standardized (unit-variance) index of the same source to obtain the regression pattern in degrees Celsius per standard deviation; amplitude is the area-weighted (cos-latitude) RMS of that regression pattern.
   - Note [eof-modes-and-pdo-index]: amplitude is the area-weighted RMS of the regression pattern in degrees Celsius per standard deviation, not the dimensionless EOF; the amplitude of the mode is compared across sources with this area weighting.

7. Persistence of the index. Dataset: the standardized monthly index of each source from step 5. Compute the lag-12-month (lag-1-year) autocorrelation of the monthly standardized index for ERSSTv5 and each model.

8. Compare the ERSSTv5-derived index with the published PDO series. Datasets: ERSSTv5 index from step 5, `cpc_indices` product `pdo`; take the Pearson correlation over 1950-2014.
   - Note [serial-correlation-and-significance]: the ERSSTv5-derived index and the published PDO series are two estimates of the same quantity, so correlate them as they are (`detrend=False`) - their shared trend is part of the agreement, not a spurious link; and pattern (spatial) correlations carry no effective-sample-size correction, so quote the coefficients rather than p-values.

9. Model-versus-observation pattern correlations. Dataset: the four regression patterns from step 6. For each model, correlate its regression pattern with the ERSSTv5 regression pattern over the cells the two sources share, using area weighting (`analyze_correlation(weighting='area')`, because the domain reaches high latitudes).
   - Note [common-comparison-mask]: do not mask the patterns to one shared mask - each mode was computed on its own source's cells; correlate each model pattern with the ERSSTv5 pattern only over the cells the pair shares, and if any shared mask is built use `ocean_only=False` here because the reference is ERSSTv5, not WOA23.

10. Observed PDO phase transitions. Dataset: the ERSSTv5 standardized monthly index from step 5. List the resulting transition years and flag which of them coincide with documented Pacific climate shifts (e.g. the 1976/77 and 1998/99 shifts).

Important:
- Computation code MUST be complete and standalone
- Let failures raise. Do NOT wrap a step in try/except to record the error and carry on: the run
  then exits cleanly with part of the answer silently missing, and the repair pass never sees the
  problem. If one model or one variable cannot be processed the way you wrote it, the right
  response is to fix the call, not to catch the exception. Only catch one when the question itself
  asks you to tolerate a missing input, and then still leave the failure in a variable the answer
  can report.
- Arrays opened with chunks (xr.open_dataset(..., chunks=...), xr.open_mfdataset) are LAZY
  (dask-backed). Every quantity you want reported must be materialised explicitly with .compute() (or
  float()) into its own small variable, otherwise the downstream step sees a dask placeholder and no
  numbers at all. Large intermediates can stay lazy.
- Regional or global means are area- or volume-weighted: for a CMIP6 model by its own areacello /
  volcello fixed fields, for a regular latitude-longitude grid by the area of each cell. Do not
  average over lat/lon with a plain .mean().
- CESM2 and MPI-ESM1-2-LR are on curvilinear grids: their index dimensions (nlat/nlon, j/i) are NOT
  geographic and cannot be sliced by value with .sel(). Subset them with a mask built from their 2-D
  latitude/longitude coordinates instead.
- CMIP6 concentrations are in mol m-3 (volume basis) while WOA23 and GLODAP are in umol kg-1 (mass
  basis); convert with the in situ density (mol m-3 = umol kg-1 * rho / 1000) before
  comparing them.
- For a region that crosses the dateline (the equatorial Pacific, 120E-280E), mind each product's
  native longitude convention (see the conventions above): such a window is contiguous on a 0-360
  axis but wraps around on a -180-180 one.
- The execution environment runs with keep_attrs enabled, so ordinary xarray operations preserve
  attributes; but when a step changes the physical quantity (a ratio, a difference of unlike
  things), set the new units yourself with .assign_attrs(units=...), or the reported units will be
  wrong.
- Visualization code can reference variables from computation
- Colour limits on a shared scale: take them from a robust percentile of the pooled data, e.g.
  `vmax = float(np.nanpercentile(np.abs(np.concatenate([...])), 98))`, and never from the maximum
  absolute value. A single coastal or marginal-sea cell is routinely an order of magnitude larger
  than the signal, and `vmax = nanmax(abs(...))` then hands the whole scale to that one cell so
  every panel renders as uniform white. Use a diverging map centred on zero for a difference or
  anomaly and a sequential map for a magnitude. When values are clipped, pass `extend='both'` (or
